Eventos em JavaScript

book_2 O que são Eventos?

Eventos são ações ou ocorrências que acontecem no navegador e que podem ser detectadas e manipuladas pelo JavaScript. Eles são fundamentais para criar interatividade em páginas web.


Principais Tipos de Eventos

Eventos de Mouse

  • click: Disparado quando o usuário clica em um elemento
  • dblclick: Disparado em um clique duplo
  • mouseenter: Quando o mouse entra na área do elemento
  • mouseleave: Quando o mouse sai da área do elemento
  • mousemove: Quando o mouse se move sobre o elemento

Eventos de Teclado

  • keydown: Disparado quando uma tecla do teclado é pressionada
  • keyup: Disparado quando uma tecla do teclado é solta
  • keypress: Quando uma tecla é pressionada (descontinuado)

Eventos de Formulários

  • submit: Disparado quando um formulário é enviado
  • reset: Disparado quando um formulário é resetado
  • change: Disparado quando o valor de um input muda
  • input: Disparado quando o valor de um input muda
  • focus: Quando um elemento recebe foco
  • blur: Quando um elemento perde o foco

Eventos Importantes

  • load: Quando a página ou recurso termina de carregar
  • scroll: Quando o usuário rola a página
  • resize: Quando a janela é redimensionada

O método de inserir o controle de eventos nas tags HTML é funcional, porém, pode ser trabalhoso e complica demais o código. Melhor seria usar o JavaScript para isso.

<!DOCTYPE html>
<html lang="pt-BR">

            font-family: Arial, sans-serif; padding: 20px;
        }
        .box {
            width: 200px; height: 100px; background-color: #3498db;
            color: white; display: flex; align-items: center;
            justify-content: center; margin: 10px 0; cursor: pointer;
        }
        #resultado {
            margin-top: 20px; padding: 10px; background-color: #ecf0f1;
            min-height: 50px; border-radius: 5px;
        }
        input {
            padding: 8px; margin: 10px 0; width: 200px;
        }
        </style>
    </head>
    <body>
        <h1>Testando Eventos</h1>
        <div class="box" onclick="registrarEvento('Click na div')">
            Clique aqui
        </div>
        <div class="box" ondblclick="registrarEvento('Duplo click na div')">
            Duplo clique aqui
        </div>
        <input type="text" placeholder="Digite algo..."
                oninput="registrarEvento('Input detectado: ' + this.value)">
        <input type="text" placeholder="Teste o focus"
                onfocus="registrarEvento('Input recebeu foco')"
                onblur="registrarEvento('Input perdeu foco')">
        <div id="resultado">
            <strong>Último evento:</strong> Nenhum ainda
        </div>

            }

    </body>

addEventListener e Funções de Resposta

book_2 Por que usar addEventListener?

O método addEventListener é a forma moderna e recomendada de trabalhar com eventos em JavaScript por diversos motivos:

  • Separação de responsabilidades:< Mantém HTML e CSS independentes dos JavaScript separados
  • Múltiplos listeners: Permite adicionar vários ouvintes ao mesmo evento
  • Remoção de eventos: Possibilita remover eventos quando necessário
  • Melhor controle: Oferece opções avançadas de configuração


Sintaxe:

elemento.addEventListener(tipo, função, opções);

Onde:

  • tipo: String com o nome do evento ('click', 'input', etc.)
  • função: Função a ser executada quando o evento ocorrer
  • opções: Parâmetro opcional com configurações


book_2 Formas de Definir Funções de Resposta

1. Função Nomeada

Definindo uma função com nome:

function trataClique() {
    alert('Botão clicado!');
}

const botao = document.getElementById('botaoExecutar');

botao.addEventListener('click', trataClique);

2. Função Anônima

Definindo uma função sem nome:

const botao = document.getElementById('botaoExecutar');

botao.addEventListener('click', 
                        function() {
                            alert('Botão clicado!');
                        } );

3. Função Arrow

Definindo uma função sem nome:

const botao = document.getElementById('botaoExecutar');

botao.addEventListener('click', () => {
                                    alert('Botão clicado!');
                                } );

O Objeto Event

book_2 O Objeto Event

Quando um evento é disparado, o JavaScript passa automaticamente um objeto event para a função de resposta:


botao.addEventListener('click', 
            function(event) {
                console.log('Tipo do evento:', event.type);
                console.log('Elemento alvo:', event.target);
                console.log('Coordenadas X:', event.clientX);
                console.log('Coordenadas Y:', event.clientY);
            } );


book_2 Propriedades Úteis do Event

  • event.target: O elemento que disparou o evento
  • event.type: O tipo de evento
  • event.preventDefault(): Previne o comportamento padrão
  • event.stopPropagation(): Para a propagação do evento


book_2 Removendo Event Listeners

function trataClique() {
    console.log('Clicou!');
}

// Adicionar
botao.addEventListener('click', trataClique);

// Remover
botao.removeEventListener('click', trataClique);

Para remover um listener, você precisa passar a mesma referência da função.

Manipulação de Formulários e Atualização de Elementos

book_2 Trabalhando com Formulários

Formulários são uma das principais formas de interação do usuário com a página. O JavaScript permite capturar e manipular dados de formulários de forma dinâmica.

book_2 Prevenindo o Comportamento Padrão

O evento submit de um formulário, por padrão, recarrega a página. Para evitar isso:

formulario.addEventListener('submit', 
            function(event) {
                event.preventDefault(); // Previne o recarregamento
                // Seu código aqui
            } );

book_2 Acessando Valores de Inputs

// Por ID
const valor = document.getElementById('meuInput').value;

// Por atributo "name" (em formulários)
const form = document.getElementById('meuForm');
const valor = form.elements['nomeDoInput'].value;

// Usando querySelector
const valor = document.querySelector('#meuInput').value;

Tipos de Inputs e Como Acessá-los

Input Text/Email/Number

const texto = document.getElementById('nome').value;

Checkbox

const checkbox = document.getElementById('aceito');

const estaMarcado = checkbox.checked; // true ou false

Radio Buttons

const radios = document.getElementsByName('genero');
let selecionado;
radios.forEach(radio => {
    if (radio.checked) {
        selecionado = radio.value;
    }
} );

Select (Dropdown)

const select = document.getElementById('estado');

const valorSelecionado = select.value;

const textoSelecionado = select.options[select.selectedIndex].text;

book_2 Atualizando Elementos Dinamicamente

Alterando Texto


elemento.textContent = 'Novo texto'; // Texto puro

elemento.innerHTML = '<strong>Novo Texto com HTML</strong>'; // Com HTML

Alterando Atributos


elemento.setAttribute('class', 'nova-classe');
elemento.src = 'nova-imagem.jpg';
elemento.disabled = true;

Alterando Estilos


elemento.style.color = 'red';
elemento.style.backgroundColor = 'yellow';
elemento.style.display = 'none';

Adicionando/Removendo Classes


elemento.classList.add('classe-nova');
elemento.classList.remove('classe-antiga');
elemento.classList.toggle('classe-alternada');
elemento.classList.contains('classe-verificar'); // retorna true/false

Validação Simples de Campos usando Eventos

book_2 Importância da Validação

A validação de formulários é essencial para:

  • Garantir que os dados estejam corretos
  • Melhorar a experiência do usuário com feedback imediato
  • Prevenir erros antes do envio
  • Reduzir requisições inválidas ao servidor

book_2 Eventos Úteis para Validação

  • input: Valida enquanto o usuário digita
  • blur: Valida quando o campo perde o foco
  • submit: Validação final antes do envio

book_2 Técnicas de Validação

Validação de Campo Vazio

if (input.value.trim() === '') {
    mostrarErro('Campo obrigatório');
}

Validação de Tamanho

if (input.value.length < 3) {
    mostrarErro('Mínimo de 3 caracteres');
}

Validação com Expressões Regulares

const regexEmail = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

if (!regexEmail.test(email.value)) {
    mostrarErro('E-mail inválido');
}

Validação de Números

const idade = parseInt(input.value);

if (isNaN(idade) || idade < 18 || idade > 100) {
    mostrarErro('Idade deve estar entre 18 e 100');
}

book_2 Feedback Visual

É importante dar feedback visual ao usuário:


function mostrarErro(input, mensagem) {
    input.classList.add('erro');
    const msgErro = document.createElement('span');
    msgErro.classList.add('mensagem-erro');
    msgErro.textContent = mensagem;
    input.parentElement.appendChild(msgErro);
}

function limparErro(input) {
    input.classList.remove('erro');
    const msgErro = input.parentElement.querySelector('.mensagem-erro');
    if (msgErro) {
        msgErro.remove();
    }
}

Eventos de Teclado e Outros Eventos Interessantes

book_2 Eventos de Teclado

Os eventos de teclado permitem capturar e responder às interações do usuário com o teclado.

Tipos de Eventos de Teclado

  • keydown: Disparado quando uma tecla do teclado é pressionada
  • keyup: Disparado quando uma tecla do teclado é solta
  • keypress: Quando uma tecla é pressionada (obsoleto)

book_2 Propriedades Importantes do Evento de Teclado

Validação de Campo Vazio

elemento.addEventListener('keydown', function(event) {
    // A tecla pressionada ('a', 'Enter', etc.)
    console.log('Tecla:', event.key);

    // Código físico da tecla ('KeyA', 'Enter')
    console.log('Código:', event.code);
    
    // true se Ctrl estiver pressionado
    console.log('Ctrl:', event.ctrlKey);
    
    // true se Shift estiver pressionado
    console.log('Shift:', event.shiftKey);

    // true se Alt estiver pressionado
    console.log('Alt:', event.altKey);

    // Código numérico (obsoleto)
    console.log('Key Code:', event.keyCode); 
} );


Teclas Especiais:
----------------
Enter: event.key === 'Enter'
Escape: event.key === 'Escape'
Setas: 'ArrowUp', 'ArrowDown', 'ArrowLeft', 'ArrowRight'
Espaço: event.key === ' ' ou event.code === 'Space'
Tab: event.key === 'Tab'


Combinações de Teclas:
---------------------
// Ctrl + S
if (event.ctrlKey && event.key === 's') {
    event.preventDefault(); // Previne salvar página
    salvarDados();
}
// Ctrl + Shift + D
if (event.ctrlKey && event.shiftKey && event.key === 'D') {
    debugMode();
}

book_2 Outros Eventos Interessantes

Eventos de Scroll


window.addEventListener('scroll', function() {
    const scrollY = window.scrollY;
    const scrollPercentage = (scrollY / (document.body.scrollHeight - window.innerHeight)) * 100;
    console.log('Scroll:', scrollPercentage.toFixed(2) + '%');
} );

Eventos de Resize


window.addEventListener('resize', function() {
    console.log('Largura:', window.innerWidth);
    console.log('Altura:', window.innerHeight);
} );

Evento de Copy/Paste


elemento.addEventListener('copy', function(event) {
    event.preventDefault();
    console.log('Tentou copiar!');
} );

elemento.addEventListener('paste', function(event) {
    event.preventDefault();
    const texto = event.clipboardData.getData('text');
    console.log('Colou:', texto);
} );

Evento de ContextMenu (Botão Direito)


elemento.addEventListener('contextmenu', function(event) {
    event.preventDefault();
    console.log('Clicou com botão direito!');
    // Pode exibir menu personalizado
} );
