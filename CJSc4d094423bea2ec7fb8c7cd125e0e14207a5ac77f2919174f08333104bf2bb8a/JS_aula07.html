Introdução

O que são funções?

book_2 Conceito

book_2 Definição

Quando começamos a programar, é comum escrever todo o código de forma linear, uma instrução após a outra. No entanto, à medida que os programas crescem, essa abordagem se torna problemática.

Imagine que vocé precisa calcular a área de vários retângulos em seu programa. Sem funções, vocé repetiria o mesmo cálculo vários vezes. Com funções, vocé escreve a lógica uma vez e a reutiliza sempre que necessário.

Funções são blocos de código organizados e nomeados que podem ser executados sempre que necesario. Elas são fundamentais para a organização e reuso de código.

Principais vantagens de usar funções:

  • Reusabilidade: Escreva uma vez, use várias vezes.
  • Manutenção: Correções e melhorias em um único lugar.
  • Legibilidade: Código mais organizado e facilmente entendido.
  • Abstração: Esconda a complexidade por trás de um nome significativo.
  • Testabilidade: Funções podem ser testadas isoladamente.

visibility Reflexão:

Pense em uma tarefa que você já programou e que repetiu código similar em vários locais. Como uma função poderia ter ajudado?

Criação de Funções

book_2 Conceito

Em JavaScript, existem várias formas de criar funções. Vamos começar com a sintaxe mais básica: a declaração de função.

visibility Sintaxe Básica

function nomeDaFuncao( ) {
    // código a ser executado
}

visibility Exemplo

// Função que exibe uma mensagem -------------

function saudacao() {
    console.log("Olá! Bem-vindo ao JavaScript!");
}

// Para executar (chamar) a função:

saudacao(); // Saída: Olá! Bem-vindo ao JavaScript!


// Função que realiza um cálculo -------------

function somarDoisMaisTres() {
    let resultado = 2 + 3;
    console.log(resultado);
}

// Para executar (chamar) a função:

somarDoisMaisTres(); // Saída: 5

visibility Importante:

Importante: A função só é executada quando você a chama pelo nome dela, seguido de parênteses ().

Parâmetros e Retorno de Valores

book_2 Conceito

Funções ficam muito mais poderosas quando podem receber dados (parâmetros) e devolver resultados (retorno).

visibility Sintaxe com parâmetros:

function nomeDaFuncao(parametro1, parametro2) {
    // código a ser executado que pode usar os parâmetros 
}

visibility Sintaxe com retorno:

function nomeDaFuncao(parametro) {
    // processamento
    return resultado;
}

visibility Exemplos simples:

// Função com um parâmetro -------------

function saudarPessoa(nome) {
console.log("Olá, " + nome + "!");
}

saudarPessoa("Maria"); // Saída: Olá, Maria!
saudarPessoa("João"); // Saída: Olá, João!

// Função com múltiplos parâmetros -------------

function somar(a, b) {
    return a + b;
}

let resultado1 = somar(5, 3);
console.log(resultado1); // Saída: 8

let resultado2 = somar(10, 20);
console.log(resultado2); // Saída: 30

// Função com parâmetros e retorno -------------

function calcularAreaRetangulo(largura, altura) {
    let area = largura * altura;
    return area;
}

let areaQuarto = calcularAreaRetangulo(4, 5);
console.log("Área do quarto: " + areaQuarto + "m²"); // Saída: Área do quarto: 20m²

visibility Importante:

Quando uma função usa return, ela retorna um ou mais valores que podem ser armazenados em variáveis ou usados em outras operações.

Escopo de Variáveis

book_2 Conceito

O escopo de uma variável determina onde ela pode ser acessada dentro do código. Em JavaScript, existem dois tipos principais de escopo: o escopo global e o escopo local.



Variáveis declaradas fora de qualquer função têm escopo global e podem ser acessadas de qualquer lugar no código.

visibility Escopo Global

let mensagemGlobal = "Eu sou global!";

function mostrarMensagem( ) {
    console.log(mensagemGlobal); // Acessa a variável global
}

mostrarMensagem( ); // Saída: Eu sou global!
console.log(mensagemGlobal); // Saída: Eu sou global!


Já variáveis declaradas dentro de uma função têm escopo local e só podem ser acessadas dentro dessa função.

visibility Escopo Local

function criarMensagem( ) {
    let mensagemLocal = "Eu sou local!";
    console.log(mensagemLocal); // Funciona
}

criarMensagem( ); // Saída: Eu sou local!
console.log(mensagemLocal); // ERRO! mensagemLocal não existe aqui


Agora vamos combinar os dois conceitos:

visibility Exemplos completo:

let contador = 0; // Esta é uma variável global

function incrementar( ) {
    let valorLocal = 1; // Variável local
    contador = contador + valorLocal;
    console.log("Dentro da função - contador: " + contador);
}

incrementar( ); // Saída: Dentro da função - contador: 1
incrementar( ); // Saída: Dentro da função - contador: 2
console.log("Fora da função - contador: " + contador); // Saída: Fora da função - contad
// console.log(valorLocal); // Isso causaria erro!

visibility Exercício 2

Objetivo: Crie um programa com uma variável global nome e uma função alterarNome que declare uma variável local também chamada nome com valor diferente. Dentro da função, exiba a variável local. Fora da função, exiba a variável global.

let nome = "Global";

function alterarNome() {
let nome = "Local";
console.log("Dentro da função - nome: " + nome);
}

alterarNome(); // Saída: Dentro da função - nome: Local
console.log("Fora da função - nome: " + nome); // Saída: Fora da função - nome: Global

visibility Boas práticas:

  • Minimize o uso de variáveis globais para evitar conflitos e facilitar a manutenção do código.
  • Prefira variáveis locais dentro de funções para encapsular dados e evitar efeitos colaterais indesejados.
  • Use nomes significativos para variáveis, tanto globais quanto locais, para melhorar a legibilidade do código.

Reutilização e Encapsulamento da Lógica

book_2 Conceito

O verdadeiro poder das funções está na capacidade de reutilizar código e de encapsular lógica complexa. Isso permite que você escreva código modularizado e reutilizável, tornando-o mais eficiente e fácil de manter.

Reutilização de Código

Quando você precisa executar a mesma tarefa múltiplas vezes, funções evitam a repetição de código. Em vez de copiar e colar o mesmo bloco de código, você simplesmente chama a função.

visibility Exemplo de reuso de código

// Sem função (código duplicado)

console.log("=== Relatório ===");
console.log("Usuário: Maria");
console.log("Idade: 25");
console.log("=================");
console.log("=== Relatório ===");
console.log("Usuário: João");
console.log("Idade: 30");
console.log("=================");

// Com função (código reutilizável)
function exibirRelatorio(nome, idade) {
    console.log("=== Relatório ===");
    console.log("Usuário: " + nome);
    console.log("Idade: " + idade);
    console.log("=================");
}

exibirRelatorio("Maria", 25);
exibirRelatorio("João", 30);

Encapsulamento de Lógica

Encapsular significa esconder a complexidade de uma operação por trás de um nome simples e significativo. Isso ajuda a manter o código organizado e facilita a manutenção.

visibility Exemplo de encapsulamento

// Função que encapsula lógica de validação

function validarIdade(idade) {
    if (idade < 0) {
        return false;
    }
    if (idade > 150) {
        return false;
    }
    return true;
}

// Uso simples, sem precisar saber os detalhes da validação

let idade1 = 25;
if (validarIdade(idade1)) {
    console.log("Idade válida!");
}

let idade2 = -5;
if (validarIdade(idade2)) {
    console.log("Idade válida!");
} else {
    console.log("Idade inválida!");
}


Agora vamos combinar os dois conceitos:

visibility Exemplo prático combinando reutilização e encapsulamento:

function calcularDesconto(preco, percentualDesconto) {
    let desconto = preco * (percentualDesconto / 100);
    let precoFinal = preco - desconto;
    return precoFinal;
}

function exibirProduto(nome, preco, desconto) {
    let precoComDesconto = calcularDesconto(preco, desconto);
    console.log("Produto: " + nome);
    console.log("Preço original: R$ " + preco);
    console.log("Preço com desconto: R$ " + precoComDesconto);
    console.log("---");
}

exibirProduto("Notebook", 3000, 10);
exibirProduto("Mouse", 50, 20);
exibirProduto("Teclado", 150, 15);

Funções Arrow

book_2 Conceito

As arrow functions (funções seta) são uma sintaxe mais concisa e moderna para escrever funções em JavaScript.

visibility Sintaxe básica

// Função tradicional
function somar(a, b) {
    return a + b;
}

// Arrow function equivalente
const somar = (a, b) => {
    return a + b;
};


Quando a função tem apenas uma expressão de retorno, podemos simplificar ainda mais:

visibility Sintaxe simplificada

// Arrow function simplificada (sem chaves e sem return)
const somar = (a, b) => a + b;


Agora vamos ver alguns exemplos:

visibility Exemplo prático combinando reutilização e encapsulamento:

// Arrow function sem parâmetros
const saudacao = () => {
    console.log("Olá!");
};

saudacao( ); // Saída: Olá!

// Arrow function com um parâmetro (parênteses opcionais)
const dobro = numero => numero * 2;
console.log(dobro(5)); // Saída: 10
console.log(dobro(10)); // Saída: 20

// Arrow function com múltiplos parâmetros
const calcularAreaRetangulo = (largura, altura) => largura * altura;
let area = calcularAreaRetangulo(5, 3);
console.log(area); // Saída: 15

// Arrow function com múltiplas linhas
const verificarMaioridade = idade => {
    if (idade >= 18) {
        return "Maior de idade";
    } else {
        return "Menor de idade";
    }
};
console.log(verificarMaioridade(20)); // Saída: Maior de idade
console.log(verificarMaioridade(15)); // Saída: Menor de idade

Objetivo: Crie uma função calcularIMC que receba peso (em kg) e altura (em metros) e retorne o IMC (Índice de Massa Corporal = peso / altura²). Depois, crie uma função classificarIMC que receba o IMC e retorne a classificação:

  • Entre 25 e 29.9: "Sobrepeso"

function calcularIMC(peso, altura) {
    return peso / (altura * altura);
}

function classificarIMC(imc) {
    if (imc < 18.5) {
        return "Abaixo do peso";
    } else if (imc < 25) {
        return "Peso normal";
    } else if (imc < 30) {
        return "Sobrepeso";
    } else {
        return "Obesidade";
    }
}

const imc = calcularIMC(70, 1.75);
console.log("IMC:", imc);
console.log("Classificação:", classificarIMC(imc));

Objetivo: Crie um sistema de notas com as seguintes funções:

Desafio

visibility Desafio

Objetivo: Crie um sistema completo de gerenciamento de uma pequena biblioteca obedecendo os seguintes requisitos:

  1. Função cadastrarLivro: Recebe título, autor, ano de publicação e número de páginas. Retorna um objeto com os dados do livro e um ID único (pode usar um contador global).
  2. Função calcularIdadeLivro: Recebe o ano de publicação e retorna quantos anos o livro tem.
  3. Função classificarTamanho: Recebe o número de páginas e retorna:
    • "Livro curto" se < 200 páginas
    • "Livro médio" se >= 200 e < 400 páginas
    • "Livro longo" se >= 400 páginas
  4. Função validarAnoPublicacao: Recebe um ano e retorna true se for válido (entre 1000 e ano atual) e false caso contrário.
  5. Função gerarResumoLivro: Recebe os dados de um livro e retorna uma string formatada com todas as informações do livro, incluindo idade e classificação de tamanho.

Teste o sistema com pelo menos 3 livros diferentes.

function cadastrarLivro(titulo, autor, anoPublicacao, numPaginas) {
    const livro = {
        id: gerarIdUnico(),
        titulo: titulo,
        autor: autor,
        anoPublicacao: anoPublicacao,
        numPaginas: numPaginas
    };
    return livro;
}

function calcularIdadeLivro(anoPublicacao) {
    const anoAtual = new Date().getFullYear();
    return anoAtual - anoPublicacao;
}

function classificarTamanho(numPaginas) {
    if (numPaginas < 200) {
        return "Livro curto";
    } else if (numPaginas < 400) {
        return "Livro médio";
    } else {
        return "Livro longo";
    }
}

function validarAnoPublicacao(ano) {
    const anoAtual = new Date().getFullYear();
    return ano >= 1000 && ano <= anoAtual;
}

function gerarResumoLivro(livro) {
    const idade = calcularIdadeLivro(livro.anoPublicacao);
    const classificacao = classificarTamanho(livro.numPaginas);
    let resposta = `Título: ${livro.titulo}\nAutor: ${livro.autor}\n`+
                    `Ano de Publicação: ${livro.anoPublicacao}\n`+
                    `Número de Páginas: ${livro.numPaginas}\n`+
                    `Idade do Livro: ${idade} anos\n`+
                    `Classificação: ${classificacao}`;
    return resposta;
}

let idCounter = 1; // Contador global para IDs únicos

function gerarIdUnico() {
    return idCounter++;
}    

// Testando o sistema com 3 livros diferentes
const livro1 = cadastrarLivro("Livro 1", "Autor 1", 2000, 300);
const livro2 = cadastrarLivro("Livro 2", "Autor 2", 2010, 500);
const livro3 = cadastrarLivro("Livro 3", "Autor 3", 2005, 400);

console.log(gerarResumoLivro(livro1));
console.log(gerarResumoLivro(livro2));
console.log(gerarResumoLivro(livro3));
