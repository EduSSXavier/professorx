book_2 Sistema de Controle de Estacionamento

Crie uma aplicação que simule um controle de estacionamento. O projeto devem ser um CRUD baseado em API implementada com JSON Server (consulte a aula anterior para instalação e uso desta ferramenta).

book_2 Requisitos:

  • Visualizar todos os veículos estacionados no momento
  • Registrar entrada de veículo (placa, modelo, cor, hora de entrada)
  • Registrar saída de veículo e calcular tempo de permanência
  • Calcular valor a pagar baseado no tempo (ex: R$ 5,00 por hora ou fração)
  • Mostrar quantidade de vagas ocupadas e disponíveis
  • Exibir relatório de faturamento do dia
  • O layout do sistema deve ser simples e intuitivo. Tente concentrar todas as funcionalidades em uma tela única, usando seus conhecimentos de manipulação do DOM.
  • OBS: Caso não deseje utizar API, você pode optar por implementar uma solução baseada em LocalStorage.

book_2 Sugestões de implementação:

  • Comece criando um layout simples com HTML e CSS. Nada de complicar. Ganhe tempo.
  • Resolva primeiro a exibição de veículos estacionados. Isso vai simplicicar a verificação das etapas seguintes.
  • Quando estiver pronto, comece a implementar a entrada de novos veículos.
  • Agora implemente a saída de veículos.
  • Verifique se a entrada e a saída de veículos está atualizando as vagas ocupadas e disponíveis.
  • Implemente a verificação de tempo de permanência e o cálculo do valor a pagar.
  • Implemente a visualização do relatório de faturamento.
