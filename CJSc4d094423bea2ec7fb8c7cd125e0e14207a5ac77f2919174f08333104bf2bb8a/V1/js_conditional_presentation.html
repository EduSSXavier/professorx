📊 Operadores Lógicos

💡 Teoria

Os operadores lógicos são usados para combinar ou modificar expressões booleanas (verdadeiro/falso). São fundamentais para criar condições complexas.

Operador Nome Descrição Resultado
&& AND (E) Verdadeiro se ambas as condições forem verdadeiras true && true = true
|| OR (OU) Verdadeiro se pelo menos uma condição for verdadeira false || true = true
! NOT (NÃO) Inverte o valor booleano !true = false

📝 Exemplo Prático

let idade = 25; let temCarteira = true; let temDinheiro = false; // AND (&&) - Todas as condições devem ser verdadeiras let podeDirigir = idade >= 18 && temCarteira; console.log(podeDirigir); // true // OR (||) - Pelo menos uma condição deve ser verdadeira let podeComprar = temDinheiro || temCarteira; console.log(podeComprar); // true // NOT (!) - Inverte o valor let naoTemDinheiro = !temDinheiro; console.log(naoTemDinheiro); // true

⚖️ Operadores de Comparação

💡 Teoria

Os operadores de comparação são usados para comparar dois valores e retornar um valor booleano (true ou false). São essenciais para tomada de decisões no código.

Operador Nome Descrição Exemplo
== Igualdade Compara valores (com conversão de tipo) 5 == "5" → true
=== Igualdade Estrita Compara valor e tipo 5 === "5" → false
!= Diferença Valores diferentes (com conversão) 5 != "3" → true
!== Diferença Estrita Valor ou tipo diferentes 5 !== "5" → true
> Maior que Primeiro valor maior 10 > 5 → true
< Menor que Primeiro valor menor 3 < 7 → true
>= Maior ou igual Maior ou igual ao segundo 5 >= 5 → true
<= Menor ou igual Menor ou igual ao segundo 4 <= 6 → true

📝 Exemplo Prático

let nota1 = 85; let nota2 = "85"; let media = 70; // Comparações de igualdade console.log(nota1 == nota2); // true (conversão automática) console.log(nota1 === nota2); // false (tipos diferentes) // Comparações numéricas console.log(nota1 > media); // true console.log(nota1 >= 85); // true console.log(media < 60); // false // Comparações com strings let nome1 = "Ana"; let nome2 = "Bruno"; console.log(nome1 < nome2); // true (ordem alfabética)

🔀 Comando IF

💡 Teoria

O comando if é a estrutura condicional mais básica em JavaScript. Ele executa um bloco de código apenas se uma condição for verdadeira (true).

Sintaxe:

if (condição) { // código executado se a condição for verdadeira }
  • A condição deve retornar um valor booleano
  • Se a condição for true, o código dentro das chaves é executado
  • Se a condição for false, o código é ignorado

📝 Exemplo Prático

let temperatura = 30; let idade = 17; let dinheiro = 50; // Exemplo 1: Verificar temperatura if (temperatura > 25) { console.log("Está calor! Use roupas leves."); } // Exemplo 2: Verificar maioridade if (idade >= 18) { console.log("Você é maior de idade."); } // Exemplo 3: Verificar se pode comprar if (dinheiro >= 30) { console.log("Você pode comprar o produto!"); dinheiro -= 30; // Subtraindo o valor da compra } console.log("Dinheiro restante: R$" + dinheiro);

🔄 Comando IF/ELSE

💡 Teoria

O comando if/else permite executar um bloco de código quando a condição é verdadeira e outro bloco quando é falsa. É uma escolha binária.

Sintaxe:

if (condição) { // código executado se a condição for verdadeira } else { // código executado se a condição for falsa }
  • Sempre executa um dos dois blocos de código
  • Útil para situações de "ou isso ou aquilo"
  • O bloco else é opcional

📝 Exemplo Prático

let idade = 16; let saldo = 150; let chuva = false; // Exemplo 1: Verificar se pode votar if (idade >= 16) { console.log("Você pode votar!"); } else { console.log("Ainda não pode votar. Aguarde completar 16 anos."); } // Exemplo 2: Verificar saldo bancário if (saldo > 100) { console.log("Você tem um bom saldo!"); } else { console.log("Cuidado com os gastos!"); } // Exemplo 3: Decidir atividade baseada no clima if (chuva) { console.log("Vou ficar em casa assistindo filme."); } else { console.log("Vou sair para caminhar no parque."); }

🔗 Comando IF/ELSE IF/ELSE

💡 Teoria

O comando if/else if/else permite testar múltiplas condições em sequência. É útil quando você tem mais de duas possibilidades.

Sintaxe:

if (condição1) { // código para condição1 } else if (condição2) { // código para condição2 } else if (condição3) { // código para condição3 } else { // código se nenhuma condição for verdadeira }
  • As condições são testadas em ordem
  • Apenas o primeiro bloco verdadeiro é executado
  • O else final é opcional, mas recomendado

📝 Exemplo Prático

let nota = 85; let temperatura = 22; // Exemplo 1: Sistema de conceitos if (nota >= 90) { console.log("Conceito A - Excelente!"); } else if (nota >= 80) { console.log("Conceito B - Muito bom!"); } else if (nota >= 70) { console.log("Conceito C - Bom!"); } else if (nota >= 60) { console.log("Conceito D - Regular."); } else { console.log("Conceito F - Reprovado."); } // Exemplo 2: Sugestão de roupa por temperatura if (temperatura >= 30) { console.log("Use roupas bem leves e beba água!"); } else if (temperatura >= 25) { console.log("Use roupas leves."); } else if (temperatura >= 15) { console.log("Use uma blusa ou casaco leve."); } else if (temperatura >= 5) { console.log("Use casaco e agasalho!"); } else { console.log("Muito frio! Use roupas bem quentes!"); }

❓ Ternários Condicionais

💡 Teoria

O operador ternário é uma forma concisa de escrever uma estrutura if/else simples. É útil para atribuições condicionais ou expressões curtas.

Sintaxe:

condição ? valorSeVerdadeiro : valorSeFalso

Como funciona:

  • Se a condição for true, retorna o primeiro valor
  • Se a condição for false, retorna o segundo valor
  • Muito útil para atribuições simples
  • Pode ser aninhado, mas cuidado com a legibilidade

📝 Exemplo Prático

let idade = 20; let nota = 75; let chuva = true; // Exemplo 1: Verificar maioridade let status = idade >= 18 ? "maior de idade" : "menor de idade"; console.log("Você é" + status); // Exemplo 2: Resultado da prova let resultado = nota >= 60 ? "Aprovado" : "Reprovado"; console.log("Resultado:" + resultado); // Exemplo 3: Atividade baseada no clima let atividade = chuva ? "ficar em casa" : "sair para passear"; console.log("Hoje vou" + atividade); // Exemplo 4: Ternário aninhado (cuidado!) let conceito = nota >= 90 ? "A" : nota >= 80 ? "B" : nota >= 70 ? "C" : "D"; console.log("Conceito:" + conceito); // Exemplo 5: Uso em função function verificarDesconto(valor) { return valor > 100 ? valor * 0.9 : valor; // 10% de desconto }

💪 Exercício de Fixação

🎯 Comando SWITCH

💡 Teoria

O comando switch é usado quando você precisa comparar uma variável com múltiplos valores específicos. É uma alternativa mais limpa ao if/else if quando você tem muitas opções.

Sintaxe:

switch (variável) { case valor1: // código para valor1 break; case valor2: // código para valor2 break; default: // código padrão }
  • case: cada possível valor da variável
  • break: evita que o código continue executando
  • default: executado se nenhum case corresponder
  • Comparação usa igualdade estrita (===)

📝 Exemplo Prático

let diaSemana = 3; let mes = "janeiro"; // Exemplo 1: Dias da semana switch (diaSemana) { case 1: console.log("Domingo - Dia de descanso!"); break; case 2: console.log("Segunda-feira - Começou a semana!"); break; case 3: console.log("Terça-feira - Vamos com tudo!"); break; case 4: console.log("Quarta-feira - Meio da semana!"); break; case 5: console.log("Quinta-feira - Quase lá!"); break; case 6: console.log("Sexta-feira - SEXTOU!"); break; case 7: console.log("Sábado - Final de semana!"); break; default: console.log("Dia inválido!"); } // Exemplo 2: Meses e estações switch (mes.toLowerCase()) { case "dezembro": case "janeiro": case "fevereiro": console.log("Estação: Verão"); break; case "março": case "abril": case "maio": console.log("Estação: Outono"); break; case "junho": case "julho": case "agosto": console.log("Estação: Inverno"); break; default: console.log("Estação: Primavera"); }

💪 Exercício de Fixação

Desafio: Crie uma calculadora simples usando switch para as operações básicas.

let num1 = 10; let num2 = 5; let operacao = "+"; // pode ser +, -, *, / let resultado; // Complete o switch: switch (operacao) { case "+": resultado = num1 + num2; console.log(`${num1} + ${num2} = ${resultado}`); break; case "-": resultado = num1 - num2; console.log(`${num1} - ${num2} = ${resultado}`); break; case "*": resultado = num1 * num2; console.log(`${num1} * ${num2} = ${resultado}`); break; case "/": if (num2 !== 0) { resultado = num1 / num2; console.log(`${num1} / ${num2} = ${resultado}`); } else { console.log("Erro: Divisão por zero!"); } break; default: console.log("Operação inválida! Use +, -, * ou /"); }

📊 Resumo e Comparação

💡 Quando usar cada estrutura?

Estrutura Quando Usar Vantagens Exemplo de Uso
IF Condição simples, uma ação Simples e direto Validar entrada de dados
IF/ELSE Duas opções mutuamente exclusivas Garante que uma ação aconteça Aprovar/Reprovar aluno
IF/ELSE IF/ELSE Múltiplas condições em sequência Flexível para condições complexas Sistema de notas A, B, C, D, F
Ternário Atribuição simples com condição Código conciso em uma linha Definir status com base em idade
SWITCH Comparar uma variável com valores específicos Código limpo para muitos casos Menu de opções, dias da semana

📝 Exemplo Comparativo

Vamos ver o mesmo problema resolvido de diferentes formas:

let nota = 85; // 1. Usando IF/ELSE IF/ELSE if (nota >= 90) { console.log("A"); } else if (nota >= 80) { console.log("B"); } else if (nota >= 70) { console.log("C"); } else { console.log("D"); } // 2. Usando Ternário Aninhado let conceito = nota >= 90 ? "A" : nota >= 80 ? "B" : nota >= 70 ? "C" : "D"; // 3. Usando função com SWITCH (para valores exatos) function getConceito(faixa) { switch (faixa) { case 4: return "A"; case 3: return "B"; case 2: return "C"; default: return "D"; } } let faixa = Math.floor(nota / 10) - 6;
