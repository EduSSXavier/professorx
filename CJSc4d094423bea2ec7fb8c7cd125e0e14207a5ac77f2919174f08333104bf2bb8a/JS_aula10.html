Introdução

O que svamos fazer hoje?

book_2 Objetivo

Iremos construir um sistema funcional de registro de visitantes em um prédio comercial integrando conceitos de arrays, objetos, funções, loops e condicionais.


O sistema também vai construir uma interface gráfica simples, manipulando elementos do DOM (hoje teremos apenas uma introdução a este tópico, que será abordado com mais profundidade em aulas futuras).


Ao final, teremos uma aplicação simples que pode ser expandida para incluir mais funcionalidades.



book_2 Detalhes da Aplicação

  • A aplicação registrará entradas e saídas de visitantes a um prédio comercial
  • Também serão emitidos 3 tipos de relatórios:
    • Visitantes por data
    • Visitantes por empresa
    • Todas as visitas

Regras de Negócio

Como funciona a aplicação?

book_2 Funções

Sua aplicação precisa definir como cada procedimento deve ser realizado.

Vamos criar funções para realizar as principais atividades.



Função Descrição
registrarEntrada(visitante, documento, proprietarioId, motivo) Registra a entrada de um visitante no prédio.
registrarSaida(visitaId) Registra a saída de um visitante do prédio.
gerarRelatorioPorData(data) Gera um relatório de todas as visitas em uma data específica.
gerarRelatorioPorProprietario(proprietarioId) Gera um relatório de todas as visitas para um proprietário específico.
gerarRelatorioCompleto() Gera um relatório completo de todas as visitas registradas.

book_2 Gestão de Interface

Agora vamos integrar as regras de negócio com a interface do usuário.

Utilizaremos comandos de manipulação do DOM para atualizar a interface com as informações das visitas.

Importante: Esta ainda não é uma aula completa sobre manipulação do DOM. Iremos abordar este tópico com mais profundidade em aulas futuras. Aqui faremos apenas uma introdução simples ao tema.



book_2 Capturando Dados do Formulário

Para capturar os dados de um campo do formulário, utilizaremos o método getElementById da seguinte maneira:

// No documento HTML o campo de entrada possui o id "campoDeEntrada"
<input type="text" id="campoDeEntrada" placeholder="Nome do visitante">

// No script JavaScript o valor do campo de entrada é capturado em uma variável
const valorCampo = document.getElementById("campoDeEntrada").value;


book_2 Definindo comportamento de botões

Para definir o comportamento de um botão, utilizaremos o método onclick da seguinte maneira:

// No documento HTML o botão define o comportamento do click
<button id="botao1" onclick="minhaFuncao()">Clique Aqui</button>

// No script JavaScript a função acionada pela ação do botão é definida
function minhaFuncao() {
    // Ação a ser executada quando o botão é clicado
    console.log("Botão clicado!");
}


book_2 Exibindo resultados na página

Para exibir resultados na página, podemos manipular o DOM utilizando o método innerHTML da seguinte maneira:

// No documento HTML o campo de saída possui o id "campoDeSaida"
<div id="campoDeSaida">
</div>

// No script JavaScript o campo de saída tem seu conteúdo HTML modificado
const campoDeSaida = document.getElementById("campoDeSaida");
campoDeSaida.innerHTML = "<p>Novo conteúdo adicionado!</p>";
