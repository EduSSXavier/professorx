Operadores Lógicos

Regras lógicas para o controle de execução

book_2 Conceito

Os operadores lógicos são usados para combinar ou modificar expressões booleanas (verdadeiro/falso). São fundamentais para criar condições complexas.

Operador Nome Descrição Resultado
&& AND (E) Verdadeiro se todas as condições forem verdadeiras true && true = true
|| OR (OU) Verdadeiro se pelo menos uma condição for verdadeira false || true = true
! NOT (NÃO) Inverte o valor booleano !true = false

visibility Exemplo

let idade = 25;
let temCarteira = true;
let temDinheiro = false;

// AND (&&) - Todas as condições devem ser verdadeiras
console.log("Pode dirigir: ", idade >= 18 && temCarteira); // true

// OR (||) - Pelo menos uma condição deve ser verdadeira
console.log("Pode comprar: ", temDinheiro || temCarteira); // true

// NOT (!) - Inverte o valor
console.log("Não tem dinheiro: ", !naoTemDinheiro);

Operadores de Comparação

Regras lógicas para comparar valores

book_2 Conceito

Os operadores de comparação são usados para comparar dois valores e retornar um valor booleano (true ou false). São essenciais para tomada de decisões no código.

Operador Nome Descrição Exemplo
== Igualdade Compara valores (com conversão de tipo) 5 == "5" → true
=== Igualdade Estrita Compara valor e tipo 5 === "5" → false
!= Diferença Valores diferentes (com conversão) 5 != "3" → true
!== Diferença Estrita Valor ou tipo diferentes 5 !== "5" → true
> Maior que Primeiro valor maior 10 > 5 → true
< Menor que Primeiro valor menor 3 < 7 → true
>= Maior ou igual Maior ou igual ao segundo 5 >= 5 → true
<= Menor ou igual Menor ou igual ao segundo 4 <= 6 → true

visibility Exemplo

let a = 5;
let b = 10;

console.log("a é igual a b:", a == b);
console.log("a é diferente de b:", a != b);
console.log("a é maior que b:", a > b);
console.log("a é menor que b:", a < b);
console.log("a é maior ou igual a b:", a ≥= b);
console.log("a é menor ou igual a b:", a ≤= b);

Comando IF

Testando condições lógicas

book_2 Conceito

O comando if é a estrutura condicional mais básica em JavaScript. Ele executa um bloco de código apenas se uma condição for verdadeira (true).

Sintaxe:

if (condição) {
    // código executado se a condição for verdadeira
}
  • A condição deve retornar um valor booleano
  • Se a condição for true, o código dentro das chaves é executado
  • Se a condição for false, o código é ignorado

visibility Exemplo

let temperatura = 30;
let idade = 17;
let dinheiro = 50;

// Exemplo 1: Verificar temperatura
if (temperatura > 25) {
    console.log("Está calor! Use roupas leves.");
}

// Exemplo 2: Verificar maioridade
if (idade >= 18) {
    console.log("Você é maior de idade.");
}

// Exemplo 3: Verificar se pode comprar
if (dinheiro >= 30) {
    console.log("Você pode comprar o produto!");
    dinheiro -= 30; // Subtraindo o valor da compra
}

console.log("Dinheiro restante: R$" + dinheiro);

Comando IF/ELSE IF/ELSE

Testando condições lógicas

book_2 Conceito

O comando if/else if/else permite testar múltiplas condições em sequência. É útil quando você tem mais de duas possibilidades.

Sintaxe:

if (condição1) {
    // código executado se condição1 for verdadeira
} else if (condição2) {
    // código executado se condição2 for verdadeira
} else {
    // código executado se nenhuma das condições anteriores for verdadeira
}
  • As condições são testadas em ordem
  • Apenas o primeiro bloco verdadeiro é executado
  • O else final é opcional, mas recomendado

visibility Exemplo

let nota = 85;
let temperatura = 22;

// Exemplo 1: Sistema de conceitos
if (nota >= 90) {
    console.log("Conceito A - Excelente!");
} else if (nota >= 80) {
    console.log("Conceito B - Muito bom!");
} else if (nota >= 70) {
    console.log("Conceito C - Bom!");
} else if (nota >= 60) {
    console.log("Conceito D - Regular.");
} else {
    console.log("Conceito F - Reprovado.");
}

 // Exemplo 2: Sugestão de roupa por temperatura
if (temperatura >= 30) {
    console.log("Use roupas bem leves e beba água!");
} else if (temperatura >= 25) {
    console.log("Use roupas leves.");
} else if (temperatura >= 15) {
    console.log("Use uma blusa ou casaco leve.");
} else if (temperatura >= 5) {
    console.log("Use casaco e agasalho!");
} else {
    console.log("Muito frio! Use roupas bem quentes!");
}

Ternários Condicionais

Simplificando a codificação de testes

book_2 Conceito

O operador ternário é uma forma concisa de escrever uma estrutura if/else simples. É útil para atribuições condicionais ou expressões curtas.

Sintaxe:

condição ? valorSeVerdadeiro : valorSeFalso

Como funciona:

  • Se a condição for true, retorna o primeiro valor
  • Se a condição for false, retorna o segundo valor
  • Muito útil para atribuições simples
  • Pode ser aninhado, mas cuidado com a legibilidade

visibility Exemplo

let idade = 20;
let nota = 75;
let chuva = true;

// Exemplo 1: Verificar maioridade
let status = idade >= 18 ? "maior de idade" : "menor de idade";
console.log("Você é "+ status);

// Exemplo 2: Resultado da prova
let resultado = nota >= 60 ? "Aprovado" : "Reprovado";
console.log("Resultado: " + resultado);

// Exemplo 3: Atividade baseada no clima
let atividade = chuva ? "ficar em casa" : "sair para passear";
console.log("Hoje vou " + atividade);

// Exemplo 4: Ternário aninhado (cuidado!)
let conceito = nota >= 90 ? "A" :
               nota >= 80 ? "B" :
               nota >= 70 ? "C" : "D";
console.log("Conceito: " + conceito);

// Exemplo 5: Uso em função
function verificarDesconto(valor) {
    return valor > 100 ? valor * 0.9 : valor; // 10% de desconto
}

Comando SWITCH

Outra forma de avalir uma variável

book_2 Conceito

O comando switch é usado quando você precisa comparar uma variável com múltiplos valores específicos. É uma alternativa mais limpa ao if/else if quando você tem muitas opções.

Sintaxe:

switch (variável) {
    case valor1:
        // código para valor1
        break;
    case valor2:
        // código para valor2
        break;
    case valor3:
        // código para valor3
        break;
    default:
        // código padrão
}

Como funciona:

  • case: cada possível valor da variável
  • break: evita que o código continue executando
  • default: executado se nenhum case corresponder

visibility Exemplo

let diaSemana = 5; // 1=Domingo, 2=Segunda, ..., 7=Sábado
let mes = "janeiro";

// Exemplo 1: Dias da semana
switch (diaSemana) {
    case 1:
        console.log("Domingo - Dia de descanso!");
        break;
    case 2:
        console.log("Segunda-feira - Começou a semana!");
        break;
    case 3:
        console.log("Terça-feira - Vamos com tudo!");
        break;
    case 4:
        console.log("Quarta-feira - Meio da semana!");
        break;
    case 5:
        console.log("Quinta-feira - Quase lá!");
        break;
    case 6:
        console.log("Sexta-feira - SEXTOU!");
        break;
    case 7:
        console.log("Sábado - Final de semana!");
        break;
    default:
        console.log("Dia inválido!");
}

 // Exemplo 2: Meses e estações
switch (mes.toLowerCase()) {
    case "dezembro":
    case "janeiro":
    case "fevereiro":
        console.log("Estação: Verão");
        break;
    case "março":
    case "abril":
    case "maio":
        console.log("Estação: Outono");
        break;
    case "junho":
    case "julho":
    case "agosto":
        console.log("Estação: Inverno");
        break;
    default:
        console.log("Estação: Primavera");
}

exercise Exercício

Desafio: Crie uma calculadora simples usando switch para as quatro operações básicas.

  • Informe dois valores e uma operação
  • Use o comando switch para avaliar a operação e executar o cálculo correspondente
  • Use um case para cada operação
  • Use um default para lidar com operações inválidas
  • Imprima o resultado na tela


let num1 = 10;
let num2 = 5;
let operacao = "+"; // pode ser +, -, * ou /
let resultado;

// Complete o switch:
switch (operacao) {
    case "+":
        resultado = num1 + num2;
        console.log(`${num1} + ${num2} = ${resultado}`);
        break;
    case "-":
        resultado = num1 - num2;
        console.log(`${num1} - ${num2} = ${resultado}`);
        break;
    case "*":
        resultado = num1 * num2;
        console.log(`${num1} * ${num2} = ${resultado}`);
        break;
    case "/":
        if (num2 !== 0) {
            resultado = num1 / num2;
            console.log(`${num1} / ${num2} = ${resultado}`);
        } else {
            console.log("Erro: Divisão por zero!");
        }
        break;
    default:
        console.log("Operação inválida! Use +, -, * ou /");
}
