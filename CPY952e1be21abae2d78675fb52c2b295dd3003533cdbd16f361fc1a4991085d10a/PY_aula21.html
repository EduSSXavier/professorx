A Despedida

Para comemorar o encerramento deste módulo vamos criar uma aplicação web completa para o cadastro e gerenciamento de clientes. O objetivo é praticar a construção de aplicações usando os conceitos aprendidos ao longo do curso.

Manteremos a ideia de separar o tratamento dos dados em um módulo dedicado (database.py) e a interface gráfica em outro arquivo (app.py). Assim, além de praticar o CRUD, você também terá a oportunidade de organizar o código de forma mais profissional.
