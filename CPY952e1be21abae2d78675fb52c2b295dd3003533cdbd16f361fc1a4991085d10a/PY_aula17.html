Banco de Dados em Python

(Parte 1)

book_2 Introdução

Em aulas anteriores criamos diversos projetos onde os dados eram armazenados em estruturas temporárias (listas, tuplas, dicionários, etc.). Porém, essa abordagem não permite a persistência dos dados, o que inviabiliza a reutilização e a escalabilidade do sistema.

Chegamos a mostrar uma solução paliativa para essa situação utilizando arquivos de texto para salvar os dados. No entanto, essa técnica apresenta diversas limitações, como a dificuldade de manipulação dos dados, a falta de segurança e a baixa performance em operações complexas.

Para superar essas limitações, nesta aula iniciaremos o estudo de bancos de dados relacionais, que são sistemas especializados em armazenar, organizar e manipular grandes volumes de dados de forma eficiente e segura.

Veremos como utilizar o SQLite, um sistema de banco de dados leve e integrado ao Python, para criar aplicações que possam armazenar e recuperar dados de forma persistente.

Ao final desta aula, você estará apto a criar um banco de dados simples, definir tabelas, inserir, consultar, atualizar e deletar registros utilizando comandos SQL básicos integrados em suas aplicações Python.
