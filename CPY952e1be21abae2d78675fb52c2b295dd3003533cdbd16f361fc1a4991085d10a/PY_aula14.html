Projeto Prático

Gerenciamento de Receitas

book_2 Introdução

Esta proposta descreve o desenvolvimento de uma aplicação CRUD (Create, Read, Update, Delete) em Python, utilizando princípios de Programação Orientada a Objetos (POO), para gerenciar receitas culinárias e itens de cozinha. A aplicação permitirá aos usuários cadastrar, visualizar, editar e excluir receitas (incluindo ingredientes e passos de preparo).


book_2 Objetivos principais:

  • Facilitar o planejamento de refeições através de receitas personalizadas.
  • Utilizar POO para modelar entidades reais (ex.: Receita como uma classe com atributos e métodos).

book_2 Modelagem Orientada a Objetos

A aplicação será estruturada em classes para representar as diferentes entidades. Usaremos herança, encapsulamento, polimorfismo e associação para uma arquitetura robusta.

  • Classe: Ingrediente
    • Ingrediente que pode ser usado em uma receita
    • Atributos: nome (str), unidade (str, ex.: "kg", "ml", "unidades")
    • Métodos:
      • __init__(self, nome, unidade)
      • descricao(self): Retorna uma string formatada com informações do ingrediente
  • Classe: Receita
    • Representa uma receita completa
    • Atributos: titulo (str), ingredientes (lista de tuplas (ingrediente, quantidade), onde ingrediente é um objeto), passos (lista de str descrevendo cada passo de preparo da receita), tempo_preparo (int, em minutos), porcoes (int).
    • Métodos:
      • __init__(self, titulo, tempo_preparo, porcoes)
      • adicionar_ingrediente(self, ingrediente, quantidade): Adiciona um objeto Ingrediente à lista
      • descricao_completa(self): Retorna uma string formatada com todos os detalhes da receita
  • Classe: GerenciadorCozinha
    • Gerencia as coleções de receitas e itens de cozinha
    • Atributos: receitas (dicionário {id: Receita,...})
    • Métodos:
      • __init__(self): menu principal
      • criar_receita(self, titulo, tempo_preparo, porcoes): Cria e adiciona uma nova Receita, retorna ID.
      • ler_receita(self, id): Retorna a Receita ou None.
      • deletar_receita(self, id): Remove a Receita.
      • criar_ingrediente(self, nome, quantidade, unidade): Cria e adiciona um novo Ingrediente, retorna ID.
      • ler_ingrediente(self, id): Retorna o Ingrediente ou None.
      • deletar_ingrediente(self, id): Remove o Ingrediente
      • buscar_receitas_por_ingrediente(self, nome_ingrediente): Retorna lista de receitas que usam o ingrediente.

book_2 Próximos Passos / Desafios:

  • Incluir a validação de informações nos métodos
  • Implementar métodos de alteração de receitas e ingredientes
  • Implementar a interface gráfica com Streamlit
  • Acrescentar uma classe para gerenciamento de itens de cozinha usados nas receitas (panelas, fornos, etc.)
