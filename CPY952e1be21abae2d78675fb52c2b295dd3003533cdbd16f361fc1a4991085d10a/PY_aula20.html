Desafio: Sistema de Gestão Escolar

Construindo uma aplicação do zero

Python Streamlit SQLite CRUD

O Desafio

Crie uma aplicação web completa para o cadastro e gerenciamento de alunos de uma escola. O objetivo é praticar a construção de interfaces rápidas com o Streamlit e a manipulação de dados com SQLite.

O diferencial deste desafio está na Arquitetura de Software: você deve separar claramente a lógica de interface da lógica de acesso a dados.

Funcionalidades Obrigatórias

  • 1. Cadastro de Alunos: Criar um formulário para inserir nome, data de nascimento, CPF e email. Os dados devem ser salvos no banco SQLite.
  • 2. Consultas com Filtros: Exibir uma tabela com todos os alunos. Implementar uma barra de busca ou filtros (ex: buscar por nome ou filtrar por faixa etária).
  • 3. Edição de Dados: Capacidade de selecionar um aluno existente e atualizar suas informações (ex: correção de nome ou email).
  • 4. Exclusão de Registros: Implementar a função de remover um aluno do banco de dados.

Arquitetura Sugerida

Para ser um bom desenvolvedor, evite colocar todo o código em um único arquivo. Separe as responsabilidades:

projeto_escola/
│
├── database.py        # Módulo de Banco de Dados
│   ├── Criar conexão
│   ├── Criar tabela (se não existir)
│   ├── Funções: adicionar_aluno(), buscar_alunos(), atualizar_aluno(), deletar_aluno()
│
├── app.py             # Interface (Streamlit)
│   ├── Aba Cadastro (Formulário)
│   ├── Aba Lista (DataFrame + Filtros)
│   ├── Lógica de Update/Delete
│
└── escola.db         # Arquivo SQLite gerado automaticamente

🚀 Desafio Extra: Gerenciamento de Turmas

Para os desenvolvedores que terminaram a tarefa inicial, aqui está o próximo nível:


  • Criar Tabela de Turmas: Além de alunos, crie uma tabela para turmas (ex: "3º Ano A", "2º Ano B") contendo o ano letivo.
  • Relacionamento: Adicione uma coluna na tabela de alunos chamada id_turma (Foreign Key). [OBS:pesquise como usar o comando SQL ALTER TABLE]
  • Alocação: No momento do cadastro ou edição do aluno, permita selecionar em qual turma ele pertence.
  • Dashboard: Crie uma aba que mostre quantos alunos existem em cada turma.
