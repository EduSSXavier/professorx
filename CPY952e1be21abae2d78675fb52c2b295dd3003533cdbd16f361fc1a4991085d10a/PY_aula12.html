Revisão de Classes e Objetos

Programação Orientada a Objetos - Parte 2

book_2 O que são Classes?

Uma classe é como um molde ou modelo que define as características (atributos) e comportamentos (métodos) que os objetos criados a partir dela terão.

book_2 O que são Objetos?

Um objeto é uma instância de uma classe. É a concretização do molde definido pela classe.


book_2 Exemplo Prático

# --- Definindo uma classe --------------
class Carro:
    # Método construtor (inicializador)
    def __init__(self, marca, modelo, ano):
        self.marca = marca# Atributo
        self.modelo = modelo# Atributo
        self.ano = ano# Atributo
        self.velocidade = 0# Atributo
    # Método
    def acelerar(self, incremento):
        self.velocidade += incremento
        print(f"O {self.modelo} acelerou para {self.velocidade} km/h")
    # Método
    def frear(self):
        self.velocidade = 0
        print(f"O {self.modelo} freou completamente")
    # Método para exibir informações
    def exibir_info(self):
        print(f"Carro: {self.marca} {self.modelo} ({self.ano})")

# --- Criando objetos (instâncias da classe Carro) --------------
carro1 = Carro("Toyota", "Corolla", 2022)
carro2 = Carro("Honda", "Civic", 2023)

# --- Usando os métodos --------------
carro1.exibir_info()
carro1.acelerar(50)
carro1.acelerar(30)
carro1.frear()

book_2 Conceitos importantes:

  • Classe: Molde que define atributos e métodos
  • Objeto: Instância concreta de uma classe
  • Atributos: Características do objeto (variáveis)
  • Métodos: Comportamentos do objeto (funções)
  • Instância: Objeto criado a partir de uma classe
  • __init__: método construtor que inicializa os atributos
  • self: referência à própria instância do objeto

book_2 Herança

Herança entre Classes

book_2 O que é Herança?

A herança permite que uma classe (classe filha ou subclasse) herde atributos e métodos de outra classe (classe mãe/pai ou superclasse). Isso promove reutilização de código e estabelece relações hierárquicas.

book_2 Sintaxe Básica:

class ClassePai:
    # código da classe pai
    pass

class ClasseFilha(ClassePai):
    # código da classe filha
    pass

book_2 Exemplo Prático:

# --- Classe base (superclasse) ---
class Animal:
    def __init__(self, nome, idade):
        self.nome = nome
        self.idade = idade

    def fazer_som(self):
        print("O animal faz um som")

    def apresentar(self):
        print(f"Nome: {self.nome}, Idade: {self.idade} anos")

# --- Classe derivada (subclasse) ---
class Cachorro(Animal):
    def __init__(self, nome, idade, raca):
    # Chama o construtor da classe pai
    Animal.__init__(self, nome, idade)
    self.raca = raca

    # Sobrescrevendo o método da classe pai
    def fazer_som(self):
        print(f"{self.nome} late: Au au!")

    # Método específico da classe Cachorro
    def buscar_bola(self):
        print(f"{self.nome} está buscando a bola!")

# --- Outra classe derivada ---
class Gato(Animal):
    def __init__(self, nome, idade, cor):
        Animal.__init__(self, nome, idade)
        self.cor = cor

    def fazer_som(self):
        print(f"{self.nome} mia: Miau!")
    
    # Método específico da classe Gato
    def arranhar(self):
        print(f"{self.nome} está arranhando o sofá!")

# --- Testando as classes ---
rex = Cachorro("Rex", 5, "Labrador")
rex.apresentar()# Método herdado
rex.fazer_som()# Método sobrescrito
rex.buscar_bola()# Método próprio
print()
mimi = Gato("Mimi", 3, "Branco")
mimi.apresentar()# Método herdado
mimi.fazer_som()# Método sobrescrito
mimi.arranhar()# Método próprio

book_2 Conceitos importantes:

  • A classe filha herda todos os atributos e métodos da classe pai
  • A classe filha pode adicionar novos atributos e métodos
  • A classe filha pode sobrescrever métodos da classe pai

book_2 Polimorfismo

Polimorfismo

book_2 O que é Polimorfismo?

Polimorfismo significa "muitas formas". Na POO, refere-se à capacidade de objetos de diferentes classes responderem ao mesmo método de maneiras diferentes.

book_2 Polimorfismo em Python

Python possui tipagem dinâmica (duck typing: "se anda como um pato e faz quack como um pato, então é um pato"). Isso significa que o Python não verifica o tipo do objeto em tempo de compilação, apenas se o objeto possui o método chamado.

book_2 Exemplos:

class Passaro:
    def voar(self):
        print("O pássaro está voando no céu")
    def emitir_som(self):
        print("O pássaro canta")

class Aviao:
    def voar(self):
        print("O avião está voando a 10.000 metros de altitude")
    def emitir_som(self):
        print("O avião faz: vrummmmm")

class Pinguim:
    def voar(self):
        print("O pinguim não consegue voar, mas nada muito bem!")
    def emitir_som(self):
        print("O pinguim faz: wak wak")

# Função que aceita qualquer objeto com método voar()
def fazer_voar(objeto):
    objeto.voar()
    objeto.emitir_som()

# Testando o polimorfismo
passaro = Passaro()
aviao = Aviao()
pinguim = Pinguim()
print("=== Polimorfismo em Ação ===")
fazer_voar(passaro)
print()
fazer_voar(aviao)
print()
fazer_voar(pinguim)


book_2 Limitações do Python

1. Ausência de Sobrecarga de Métodos Tradicional

Em Python, a sobrecarga de métodos tradicional (overloading) não é suportada. Se você definir múltiplos métodos com o mesmo nome, o último definido sobrescreverá os anteriores.

class Calculadora:
    # Em Java/C++, poderíamos ter múltiplos métodos soma()
    # com diferentes assinaturas. Em Python, isso NÃO funciona:
    def soma(self, a, b):
        return a + b        
    # Este método substitui o anterior!
    def soma(self, a, b, c):
        return a + b + c

calc = Calculadora()
# calc.soma(2, 3) # Retoarna um ERRO! Precisa de 3 argumentos
print(calc.soma(2, 3, 4)) # Funciona

# Solução em Python: usar argumentos padrão ou *args
class CalculadoraMelhorada:
    def soma(self, *numeros):
        return sum(numeros)

calc2 = CalculadoraMelhorada()
print(calc2.soma(2, 3)) # Funciona
print(calc2.soma(2, 3, 4, 5)) # Funciona também

2. Não há Verificação de Tipo em Tempo de Compilação

Python permite passar qualquer objeto para qualquer função, desde que o objeto tenha os métodos necessários. Isso é muito flexível, mas pode causar erros em tempo de execução.

def processar_pagamento(conta):
    conta.debitar(100)  # Python só verifica se o método existe em runtime
                        # Isso pode causar erro se conta não tiver o método debitar()

3. Não há Interfaces ou Classes Abstratas Nativas Estritas

Embora Python tenha o módulo abc (Abstract Base Classes), o uso é opcional e não é obrigatório como em Java.

from abc import ABC, abstractmethod

class FormaAbstrata(ABC):
    @abstractmethod
    def calcular_area(self):
        pass

class Quadrado(FormaAbstrata):
    pass 
    # ERRO: não implementou calcular_area()

class Circulo(FormaAbstrata):
    def __init__(self, raio):
        self.raio = raio
    def calcular_area(self):
        return 3.14 * self.raio ** 2
    # Funciona porque implementou o método abstrato

c = Circulo(5)
print(f"Área do círculo: {c.calcular_area()}")

book_2 Uso de super()

super()

book_2 O que é super()?

super() é uma função em Python que permite chamar métodos da classe pai de uma forma segura e elegante.

book_2 Por que usar super()?

  • Manutenibilidade: Se mudar o nome da classe pai, nao precisa atualizar múltiplas referências
  • Herança Múltipla: super() funciona corretamente com herança múltipla (um filho herdando de multiplos pais)
  • Código mais limpo: Torna o código mais legível e profissional

book_2 Exemplo:

class Pessoa:
    def __init__(self, nome, idade):
        self.nome = nome
        self.idade = idade
        print(f"Construtor de Pessoa chamado para {nome}")

    def apresentar(self):
        print(f"Olá, meu nome é {self.nome} e tenho {self.idade} anos")

class Estudante(Pessoa):
    def __init__(self, nome, idade, matricula):
        # Usando super() para chamar o construtor da classe pai
        super().__init__(nome, idade)
        self.matricula = matricula
        print(f"Construtor de Estudante chamado")

    def apresentar(self):
        # Usando super() para chamar o método da classe pai
        super().apresentar()
        print(f"Minha matrícula é {self.matricula}")

class Atleta(Pessoa):
    def __init__(self, nome, idade, esporte):
        super().__init__(nome, idade)
        self.esporte = esporte

    def apresentar(self):
        super().apresentar()
        print(f"Eu pratico {self.esporte}")

# Testando as classes

print("=== Criando Estudante ===")
est = Estudante("Ana", 20, "2023001")
est.apresentar()
print("\n=== Criando Atleta ===")
atl = Atleta("Carlos", 22, "Futebol")
atl.apresentar()


book_2 Herança Múltipla

Herança múltipla é quando uma classe pode herdar atributos e métodos de mais de uma classe pai ao mesmo tempo.

Python é uma das poucas linguagens populares que suportam herança múltipla nativamente (junto com C++, por exemplo). Em Java ou C#, isso é proibido diretamente, mas simulado com interfaces.

book_2 Exemplo:

class Animal:
    def __init__(self, nome, idade):
        self.nome = nome
        self.idade = idade
        print(f">>> Animal.__init__ chamado -> {self.nome}, {self.idade} anos")

class Voador:
    def __init__(self, altitude_maxima):
        self.altitude_maxima = altitude_maxima
        print(f">>> Voador.__init__ chamado -> altitude máxima {self.altitude_maxima}m")

class Nadador:
    def __init__(self, profundidade_maxima):
        self.profundidade_maxima = profundidade_maxima
        print(f">>> Nadador.__init__ chamado -> profundidade máxima {self.profundidade_maxima}m")

# Ordem das classes pai importa para o MRO!
class Pato(Animal, Voador, Nadador):
    def __init__(self, nome, idade, altitude_maxima=100, profundidade_maxima=5):
        self.especie = "Pato"
        print("Pato.__init__ começando...")
        Animal.__init__(self, nome, idade)
        Voador.__init__(self, altitude_maxima)
        Nadador.__init__(self, profundidade_maxima)
        print("Pato completamente inicializado!\n")

# Testando
pato1 = Pato(
    nome="Donald",
    idade=7,
    altitude_maxima=150,
    profundidade_maxima=8
)

print("Atributos do pato:")
print(f"Nome: {pato1.nome}")
print(f"Idade: {pato1.idade}")
print(f"Altitude máxima: {pato1.altitude_maxima}m")
print(f"Profundidade máxima: {pato1.profundidade_maxima}m")

book_2 Projeto Pronto: Sistema de Funcionários

Vamos observar um sistema de gerenciamento de funcionários aplicando os conceitos aprendidos.

class Funcionario:
    """Classe base para todos os funcionários"""

    contador_funcionarios = 0 # Atributo de classe (não das instâncias)

    def __init__(self, nome, cpf, salario_base):
        self.nome = nome
        self.cpf = cpf
        self.salario_base = salario_base
        Funcionario.contador_funcionarios += 1
        self.id = Funcionario.contador_funcionarios

    def calcular_salario(self):
        """Calcula o salário do funcionário"""
        return self.salario_base

    def exibir_info(self):
        """Exibe informações básicas do funcionário"""
        print(f"ID: {self.id}")
        print(f"Nome: {self.nome}")
        print(f"CPF: {self.cpf}")
        print(f"Salário: R$ {self.calcular_salario():.2f}")

    def __str__(self):
        return f"{self.nome} (ID: {self.id})"

class Professor(Funcionario):
    """Classe para professores"""
    def __init__(self, nome, cpf, salario_base, disciplina, nivel):
        super().__init__(nome, cpf, salario_base)
        self.disciplina = disciplina
        self.nivel = nivel # "Fundamental", "Médio", "Superior"
        self.bonus_nivel = {"Fundamental": 1.0, "Médio": 1.2, "Superior": 1.5}

    def calcular_salario(self):
        """Professores recebem bônus por nível de ensino"""
        multiplicador = self.bonus_nivel.get(self.nivel, 1.0)
        return self.salario_base * multiplicador

    def exibir_info(self):
        super().exibir_info()
        print(f"Disciplina: {self.disciplina}")
        print(f"Nível: {self.nivel}")

    def dar_aula(self):
        print(f"{self.nome} está ministrando aula de {self.disciplina}")

class Coordenador(Funcionario):
    """Classe para coordenadores"""
    def __init__(self, nome, cpf, salario_base, setor, numero_funcionarios):
        super().__init__(nome, cpf, salario_base)
        self.setor = setor
        self.numero_funcionarios = numero_funcionarios

    def calcular_salario(self):
        """Coordenadores recebem bônus por funcionário supervisionado"""
        bonus = self.numero_funcionarios * 100
        return self.salario_base + bonus
        
    def exibir_info(self):
        super().exibir_info()
        print(f"Setor: {self.setor}")
        print(f"Funcionários sob supervisão: {self.numero_funcionarios}")

    def organizar_reuniao(self):
        print(f"{self.nome} está organizando reunião do setor {self.setor}")

class Diretor(Coordenador):
    """Classe para diretores (herda de Coordenador)"""
    def __init__(self, nome, cpf, salario_base, setor, numero_funcionarios, bonus_anual):
        super().__init__(nome, cpf, salario_base, setor, numero_funcionarios)
        self.bonus_anual = bonus_anual

    def calcular_salario(self):
        """Diretores recebem salário de coordenador + bônus anual mensal"""
        salario_coordenador = super().calcular_salario()
        return salario_coordenador + (self.bonus_anual / 12)

    def exibir_info(self):
        super().exibir_info()
        print(f"Bônus Anual: R$ {self.bonus_anual:.2f}")

    def tomar_decisao_estrategica(self):
        print(f"{self.nome} está tomando decisões estratégicas para a instituição")

# Testando o sistema
print("=== SISTEMA DE GERENCIAMENTO DE FUNCIONÁRIOS ===\n")

# Criando funcionários
prof1 = Professor("Maria Silva", "123.456.789-00", 3000, "Matemática", "Médio")
prof2 = Professor("João Santos", "987.654.321-00", 3000, "Física", "Superior")
coord1 = Coordenador("Ana Paula", "456.789.123-00", 5000, "Pedagógico", 15)
diretor1 = Diretor("Carlos Eduardo", "789.123.456-00", 8000, "Geral", 50, 24000)

# Lista de funcionários (polimorfismo)
funcionarios = [prof1, prof2, coord1, diretor1]

# Exibindo informações de todos
for func in funcionarios:
    print("="*50)
    func.exibir_info()
    print()

# Demonstrando métodos específicos
print("="*50)
print("=== AÇÕES ESPECÍFICAS ===\n")
prof1.dar_aula()
coord1.organizar_reuniao()
diretor1.tomar_decisao_estrategica()

# Calculando folha de pagamento total
print("\n" + "="*50)
print("=== FOLHA DE PAGAMENTO ===\n")
total_folha = sum(func.calcular_salario() for func in funcionarios)
print(f"Total de funcionários: {len(funcionarios)}")
print(f"Custo total da folha: R$ {total_folha:.2f}")
