book_2 O que é um "Paradigma"?

Paradigma significa um modelo, um padrão, um exemplo ou uma estrutura teórica que serve de referência e estabelece os limites de como algo é compreendido ou feito.

book_2 E um Paradigma de Programação?

Um paradigma de programação é uma abordagem ou estilo fundamental para escrever código, funcionando como uma "filosofia" ou "modelo" para estruturar e organizar programas.
Em outras palavras, ele molda a abordagem e a maneira como os programadores pensam e resolvem problemas, oferecendo um conjunto de regras, técnicas e abstrações que determinam como a lógica é construída e o software é executado.
A escolha do paradigma impacta a eficiência, legibilidade e manutenibilidade do código.

book_2 O Paradigma de Programação Orientada a Objetos

A Programação Orientada a Objetos (POO) é um paradigma de programação que organiza o código em torno de "objetos" que representam entidades do mundo real.
Imagine que você está criando um sistema para gerenciar uma biblioteca: você teria objetos como Livro, Usuário, Empréstimo, Autor, Editora, etc.

book_2 Conceitos Fundamentais:

  • Classe: Uma classe define o comportamento e a estrutura de um objeto. É como um "molde" ou "planta baixa" que define as características e comportamentos de um objeto.
  • Objeto: É uma instância concreta de uma classe. Se a classe é o molde, o objeto é o bolo feito com esse molde.
  • Atributos: São as características ou propriedades de um objeto (ex: cor, tamanho, nome).
  • Métodos: São as ações ou comportamentos que um objeto pode realizar (ex: andar, calcular, exibir).

book_2 Exemplo Conceitual:

# Classe Cachorro - o molde
class Cachorro:
    def __init__(self, nome_cachorro, raca_cachorro):
        self.nome = nome_cachorro
        self.raca = raca_cachorro
    def latir(self):
        return f"{self.nome} diz: Au au!"

# Objetos - cachorros específicos criados a partir do molde
rex = Cachorro("Rex", "Labrador")
bob = Cachorro("Bob", "Poodle")
print(rex.latir()) # Rex diz: Au au!
print(bob.latir()) # Bob diz: Au au!

Diferença entre Programação Funcional e Orientada a Objetos

book_2 Programação Funcional

Na programação funcional, o código é organizado em funções independentes que processam dados. Os dados e as funções que os manipulam ficam separados.

book_2 Exemplo:

# Exemplo Funcional
def calcular_area_retangulo(largura, altura):
    return largura * altura

def calcular_perimetro_retangulo(largura, altura):
    return 2 * (largura + altura)

# Dados separados das funções
largura = 5
altura = 3
area = calcular_area_retangulo(largura, altura)
perimetro = calcular_perimetro_retangulo(largura, altura)

book_2 Programação Orientada a Objetos

Na POO, dados e funções ficam juntos dentro de uma classe, formando uma unidade coesa.

book_2 Exemplo:

# Exemplo Orientado a Objetos
class Retangulo:
    def __init__(self, largura, altura):
        self.largura = largura
        self.altura = altura
    def calcular_area(self):
        return self.largura * self.altura
    def calcular_perimetro(self):
        return 2 * (self.largura + self.altura)

# Objeto que contém dados E comportamentos
meu_retangulo = Retangulo(5, 3)
area = meu_retangulo.calcular_area()
perimetro = meu_retangulo.calcular_perimetro()

book_2 Comparação:

Aspecto Programação Funcional Programação Orientada a Objetos
Organização Funções separadas Dados + Métodos juntos
Reutilização Funções reutilizáveis Classes reutilizáveis
Adequação Tarefas específicas Sistemas complexos

Criando Classes e Instâncias

book_2 Classes

Uma classe é definida usando a palavra-chave class , seguida do nome da classe (sempre com letra maiúscula, por convenção).

book_2 Exemplos:

# Definindo uma classe
class Carro:
    pass # pass indica que a classe está vazia por enquanto

# Criando instâncias (objetos) da classe
carro1 = Carro()
carro2 = Carro()
print(type(carro1)) # <class '__main__.Carro'> ou <class '__main__.Carro'>
print(carro1 == carro2) # False - são objetos diferentes

book_2 Exemplo com Atributos:

# Definindo uma classe
class Pessoa:
    especie = "Homo sapiens" # Atributo de classe (compartilhado)

# Criando instâncias
pessoa1 = Pessoa()
pessoa2 = Pessoa()
print(pessoa1.especie) # Homo sapiens
print(pessoa2.especie) # Homo sapiens

Atributos e Métodos

book_2 Atributos

Atributos são variáveis que pertencem a um objeto. Existem dois tipos:

  • Atributos de instância: Específicos de cada objeto
  • Atributos de classe: Compartilhados por todos os objetos
class Computador:
    # Atributo de classe
    tipo = "Desktop"

    def criar_atributos(self, marca, processador, ram):
        # Atributos de instância
        self.marca = marca
        self.processador = processador
        self.ram = ram

# Criando objetos
pc1 = Computador()
pc1.criar_atributos("Dell", "Intel i5", 8)
pc2 = Computador()
pc2.criar_atributos("HP", "AMD Ryzen 5", 16)
print(pc1.marca) # Dell
print(pc2.ram) 
# 16
    print(pc1.tipo) # Desktop (atributo de classe)


book_2 Métodos

Métodos são funções definidas dentro de uma classe. O primeiro parâmetro é sempre self, que representa a própria instância.

class Calculadora:
    def somar(self, a, b):
        return a + b
    def subtrair(self, a, b):
        return a - b
    def multiplicar(self, a, b):
        return a * b

calc = Calculadora()
print(calc.somar(5, 3)) # 8
print(calc.multiplicar(4, 7)) # 28


book_2 Exemplo Completo:

class Produto:
    def __init__(self, nome, preco):
        self.nome = nome
        self.preco = preco
        self.quantidade = 0
    def adicionar_estoque(self, quantidade):
        self.quantidade += quantidade
        print(f"{quantidade} unidades adicionadas. Estoque atual: {self.quantidade}")
    def vender(self, quantidade):
        if quantidade <= self.quantidade:
            self.quantidade -= quantidade
            total = quantidade * self.preco
            print(f"Venda realizada! Total: R${total:.2f}")
            return total
        else:
            print("Estoque insuficiente!")
            return 0

# Usando a classe
notebook = Produto("Notebook Dell", 3500.00)
notebook.adicionar_estoque(10) # 10 unidades adicionadas. Estoque atual: 10
notebook.vender(3) # Venda realizada! Total: R$10500.00

Construtor "init"

book_2 Construtor init

O método __init__ é um construtor especial que é executado automaticamente quando criamos uma nova instância. Ele é geralmente usado para inicializar os atributos do objeto.

book_2 Por que usar __init__ ?

Sem o construtor, precisaríamos definir os atributos manualmente após criar o objeto:

# SEM __init__ (trabalhoso)
class Pessoa:
    pass

p = Pessoa()
p.nome = "João"
p.idade = 25


Com o construtor, inicializamos tudo de uma vez:

# COM __init__ (prático)
class Pessoa:
    def __init__(self, nome, idade):
        self.nome = nome
        self.idade = idade

p = Pessoa("João", 25) # Atributos já definidos!


book_2 Exemplo Detalhado:

Sem o construtor, precisaríamos definir os atributos manualmente após criar o objeto:

class Estudante:
    def __init__(self, nome, matricula, curso):
        self.nome = nome
        self.matricula = matricula
        self.curso = curso
        self.notas = [] # Inicializa com lista vazia
    def adicionar_nota(self, nota):
        self.notas.append(nota)
    def calcular_media(self):
        if len(self.notas) == 0:
            return 0
        return sum(self.notas) / len(self.notas)
    def exibir_info(self):
        print(f"Estudante: {self.nome}")
        print(f"Matrícula: {self.matricula}")
        print(f"Curso: {self.curso}")
        print(f"Média: {self.calcular_media():.2f}")

# Criando estudantes
aluno1 = Estudante("Maria Silva", "2023001", "Engenharia")
aluno1.adicionar_nota(8.5)
aluno1.adicionar_nota(9.0)
aluno1.adicionar_nota(7.5)
aluno1.exibir_info()


book_2 Parâmetros Opcionais no init:

Sem o construtor, precisaríamos definir os atributos manualmente após criar o objeto:

class Livro:
    def __init__(self, titulo, autor, ano=2024, disponivel=True):

# Diferentes formas de criar objetos

Projeto Prático 2

book_2 Projeto: Catálogo de Filmes para Streaming

Crie uma classe Filme que represente um filme em uma plataforma de streaming. A classe deve ter:

book_2 Atributos:

  • titulo (string)
  • ano (int)
  • diretor (string)
  • genero (string)
  • duracao (int, em minutos)
  • avaliacao (float, de 0 a 5)
  • visualizacoes (int, inicia em 0)

book_2 Métodos:

  • reproduzir() - incrementa o contador de visualizações
    e exibe mensagem
  • avaliar(nota) - atualiza a avaliação média (deve aceitar
    notas de 0 a 5)
  • exibir_informacoes() - imprime todos os dados do filme
    formatados
  • eh_lancamento() - retorna True se o filme foi lançado
    há menos de 2 anos, False caso contrário
  • duracao_formatada() - retorna a duração no formato
    "Xh Ymin"


book_2 Exemplo de uso experado:

# Criar filme
filme1 = Filme("A Origem", "Christopher Nolan", 2010, "Ficção Científica", 148, 4.8)

# Reproduzir
filme1.reproduzir() # "Reproduzindo: A Origem"

# Avaliar
filme1.avaliar(5.0)

# Verificar se é lançamento
print(filme1.eh_lancamento()) # False (filme de 2010)

# Exibir duração formatada
print(filme1.duracao_formatada()) # "2h 28min"

# Exibir informações completas
filme1.exibir_informacoes()
