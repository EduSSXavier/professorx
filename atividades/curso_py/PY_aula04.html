book_2 Conceito e Criação de Funções

Funções

Blocos de códigos reutilizáveis

book_2 Definição

Uma função é um bloco de código reutilizável que realiza uma tarefa específica. Em Python, definimos funções usando o comando def.

visibility Sintaxe

def nome_da_funcao( ):
    # corpo da função
    print("Olá, mundo!")

visibility Exemplo

# Definindo a função
def saudacao( ):
    print("Bem-vindo ao curso de Python!")
    print("Vamos aprender sobre funções!")

# Chamando a função
saudacao( )

Parâmetros e Argumentos

Criando funções mais complexas

book_2 Definição

Parâmetros são variáveis listadas na definição da função, enquanto argumentos são os valores passados para a função quando ela é chamada.

Imagine os parâmetros como "caixas" que recebem valores, enquanto argumentos são os valores colocados nessas caixas.

visibility Exemplos

# --- Exemplo com um parâmetro:

def saudar_pessoa(nome):
    print(f"Olá, {nome}! Seja bem-vindo!")


saudar_pessoa("João") # "João" é o argumento


# --- Exemplo com múltiplos parâmetros:

def calcular_soma(a, b):
    resultado = a + b
    print(f"A soma de {a} + {b} = {resultado}")

calcular_soma(5, 3)

# --- Exemplo com parâmetros com valores padrão:

def saudar(nome, saudacao="Olá"):
    print(f"{saudacao}, {nome}!")

saudar("Maria") # Usa o valor padrão
saudar("Pedro", "Bom dia") # Substitui o valor padrão

Return

Retorno de Valores

book_2 Definição

A instrução return permite que uma função devolva um valor ao código que a chamou. Isso torna as funções muito mais úteis e versáteis.

visibility Exemplos

# --- Retornando um único valor:

def somar(a, b):
    return a + b

resultado = somar(10, 5)
print(f"O resultado é: {resultado}")

# --- Retornando múltiplos valores:

def operacoes(a, b):
    soma = a + b
    subtracao = a - b
    multiplicacao = a * b
    return soma, subtracao, multiplicacao

resultado1, resultado2, resultado3 = operacoes(10, 5)
print(f"Soma: {resultado1}, Subtração: {resultado2}, Multiplicação: {resultado3}")

visibility Importante:

Para retornar um valor, a função precisa ter um return.

Após o return, a função é encerrada.

Se a função não tiver um return, ela retornará None automaticamente por padrão.

book_2 Escopos de Variáveis

Escopo de Variáveis

book_2 Explicação

O escopo determina onde uma variável pode ser acessada no código. Variáveis definidas dentro de uma função não podem ser acessadas fora dela.

book_2 Escopo LOCAL

Variáveis definidas dentro de uma função só existem dentro dela.

visibility Exemplo

def minha_funcao():
    variavel_local = 10     # Só existe dentro da função
    print(variavel_local)   # Isso funciona!

minha_funcao()
# print(variavel_local) # Isso causaria um erro!

book_2 Escopo GLOBAL

Variáveis definidas fora de funções podem ser acessadas em qualquer lugar.

visibility Exemplo

variavel_global = 20

def mostrar_global():
    print(variavel_global) # Isso funciona. Acessa a variável global.

mostrar_global()
print(variavel_global) # Isso também funciona.

book_2 Modificando variáveis globais:

Para modificar uma variável global dentro de uma função, use global.

visibility Exemplo

contador = 0

def incrementar( ):
    global contador
    contador += 1
    print(f"Contador: {contador}")

incrementar( )
incrementar( )

visibility Boa prática:

Evite usar variáveis globais quando possível. Prefira passar valores como parâmetros e retornar resultados.

Variáveis globais são desaconselháveis em funções Python porque tornam o código imprevisível, difícil de depurar e de reutilizar, aumentando o risco de conflitos de nome e alterações acidentais que podem gerar bugs, afetando a modularidade e a manutenção do programa./p>

exercise Exercício 4:

Objetivo: Crie um programa com uma variável global saldo = 1000. Crie duas funções:

  • depositar(valor): adiciona o valor ao saldo
  • sacar(valor): subtrai o valor do saldo se houver saldo suficiente


# Definindo a variável global
saldo = 1000

# Definindo as funções
def depositar(valor):
    global saldo
    saldo += valor

def sacar(valor):
    global saldo
    if valor <= saldo:
        saldo -= valor
    else:
        print("Saldo insuficiente!")

# Chamando as funções
depositar(500)
sacar(200)
print(f"Saldo atual: {saldo}")

book_2 Funções Lambda (Anônimas)

Funções Lambda

Como criar funções anônimas

book_2 Conceito

Funções lambda, ou funções anônimas, são funções definidas sem um nome. Elas são úteis para operações simples e podem ser criadas em uma única linha.

visibility Sintaxe:

lambda argumentos: expressão

visibility Exemplo

# Função tradicional
def quadrado(x):
    return x ** 2

# Função lambda equivalente
quadrado_lambda = lambda x: x ** 2

print(quadrado(5))
print(quadrado_lambda(5))

book_2 4. Evite efeitos colaterais não intencionais:

Uma boa prática para evitar efeitos colaterais não intencionais é utilizar parâmetros de entrada e saída claros e evitar modificar variáveis globais.

visibility Exemplo:

def adicionar_item(lista, item):
    lista.append(item)
    return lista

exercise Exercício 7:

Validador de Senha: Crie uma função validar_senha(senha) que retorne True se a senha atender a todos os critérios:

  • Mínimo de 8 caracteres
  • Pelo menos uma letra maiúscula
  • Pelo menos uma letra minúscula
  • Pelo menos um número
  • Pelo menos um caractere especial (!@#$%&*)

Dica: Use métodos de string como any(), isupper(), islower(), isdigit().



def validar_senha(senha):
    tamanhoMinimo = False
    peloMenosUmaMaiuscula = False
    peloMenosUmaMinuscula = False
    peloMenosUmNumero = False
    peloMenosUmEspecial = False

    if len(senha) >= 8:
        tamanhoMinimo = True

    for letra in senha:
        #teste de maiuscula
        if letra.isupper():
            peloMenosUmaMaiuscula = True
        #teste de minuscula
        if letra.islower():
            peloMenosUmaMinuscula = True
        #teste de numero
        if letra.isdigit():
            peloMenosUmNumero = True
        #teste de especial
        if letra in "!@#$%&*":
            peloMenosUmEspecial = True

    if tamanhoMinimo and peloMenosUmaMaiuscula and \
       peloMenosUmaMinuscula and peloMenosUmNumero and \
       peloMenosUmEspecial:
        return True
    return False

print(validar_senha("Senha123!"))
print(validar_senha("senha123"))
print(validar_senha("SENHA123"))
print(validar_senha("Senha!"))
print(validar_senha("Senha123"))
print(validar_senha("Senha1234"))
print(validar_senha("Senha!@#"))
print(validar_senha("Senha123!@#"))

exercise DESAFIO:

Gerador de Relatório de Vendas: Crie um sistema com as seguintes funções:

  1. Criar uma lista de vendas vazia
  2. Criar uma função para registrar uma venda
  3. Criar uma função para calcular o total de vendas
  4. Criar uma função para calcular o produto mais vendido
  5. Criar uma função para gerar um relatório formatado com as seguintes informações:
    • Total de vendas realizadas
    • Valor total arrecadado
    • Produto mais vendido
    • Ticket médio (valor total / número de vendas)

Estrutura de dados sugerida:

vendas = [ ]

# Cada venda é um dicionário: {'produto': str, 'quantidade': int, 'preco': float}
                


# --- Dados de vendas

vendas = []

# --- Funções

def registrar_venda(produto, quantidade, preco):
    venda = {'produto': produto, 'quantidade': quantidade, 'preco': preco}
    vendas.append(venda)

def calcular_total_vendas():
    total = 0
    for venda in vendas:
        total += venda['quantidade'] * venda['preco']
    return total

def calcular_produto_mais_vendido():
    mais_vendido = None
    maior_quantidade = 0
    for venda in vendas:
        if venda['quantidade'] > maior_quantidade:
            mais_vendido = venda['produto']
            maior_quantidade = venda['quantidade']  
    return mais_vendido

def gerar_relatorio():
    total_vendas = calcular_total_vendas()
    produto_mais_vendido = calcular_produto_mais_vendido()
    ticket_medio = total_vendas / len(vendas)
    relatorio = f"Total de vendas: {total_vendas}\n"
    relatorio += f"Produto mais vendido: {produto_mais_vendido}\n"
    relatorio += f"Ticket médio: {ticket_medio:.2f}"
    return relatorio

# --- Exemplo de uso

registrar_venda("Produto A", 3, 10.0)
registrar_venda("Produto B", 5, 20.0)
registrar_venda("Produto A", 2, 10.0)

print(gerar_relatorio())
