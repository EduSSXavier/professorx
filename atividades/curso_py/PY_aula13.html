book_2 O Conceito de Encapsulamento

Encapsulamento é um dos pilares fundamentais da Programação Orientada a Objetos (POO). Ele consiste em "esconder" os detalhes internos de uma classe, protegendo os dados e controlando como eles são acessados e modificados.


book_2 Por que encapsular?

  • Segurança: Proteger os dados internos da classe, evitando que eles sejam acessados diretamente ou modificados de fora dela
  • Manutenibilidade: Permitir que as classes sejam modificadas sem afetar outras partes do código
  • Controle de acesso: Define quem pode ler ou modificar os dados
  • Validação: Permite verificar dados antes de armazená-los e evitar erros
  • Flexibilidade: Permite a adição de novos comportamentos sem afetar o código existente

book_2 Níveis de visibilidade em Python

Em Python, a visibilidade é indicada por convenção através de underscores:

  • Público: atributo - pode ser acessado de qualquer lugar
  • Privado: _atributo - indica visibilidade interna ou uso interno (convenção, não bloqueio real)
  • Protegido: __atributo - dificulta o acesso externo através de name mangling (ou mutilação/confusão de nomes)

book_2 Exemplo:

class Pessoa:
    def __init__(self, nome, email, fone):
        self.nome = nome # Atributo público
        self._email = email # Atributo privado
        self.__fone = fone # Atributo protegido
    def apresentar(self):
        print("==============================")
        print(f"Olá, meu nome é {self.nome}")
        print(f"Meu email é {self._email}")
        print(f"Meu telefone é {self.__fone}")
        print("==============================")

alguem = Pessoa("Maria", "maria@gmail.com", "9999-9999")
print(alguem.nome)      # Isto funciona
print(alguem._email)    # Isto também funciona, mas não deve ser usado
print(alguem.__fone)    # Isto não funciona (erro)

alguem.apresentar()

Encapsulamento em Python:
Métodos Getter e Setter

book_2 Como funciona?

Podemos métodos "getter" e "setter" tradicionais. Essa é uma abordagem é mais explícita e comum em outras linguagens como Java, podendo ser facilmente implementada em Python.

book_2 Exemplo:

class Produto:
    def __init__(self, nome, preco):
        self.__nome = nome # Atributo privado
        self.__preco = preco
    
    # Getter para nome
    def get_nome(self):
        return self.__nome
    
    # Setter para nome
    def set_nome(self, nome):
        if not nome or len(nome) < 3:
            raise ValueError("Nome deve ter pelo menos 3 caracteres")
        self.__nome = nome

    # Getter para preço
    def get_preco(self):
        return self.__preco

    # Setter para preço
    def set_preco(self, preco):
        if preco < 0:
            raise ValueError("Preço não pode ser negativo")
        self.__preco = preco

    # Outros métodos da classe
    def aplicar_desconto(self, percentual):
        """Aplica desconto ao produto"""
        if percentual < 0 or percentual > 100:
            raise ValueError("Desconto deve estar entre 0 e 100%")
        desconto = self.__preco * (percentual / 100)
        self.__preco -= desconto
        print(f"Desconto de {percentual}% aplicado!")

# ----- Como usar -----

# Criando produto
produto = Produto("Notebook", 3000)

# Usando getters
print(f"Produto: {produto.get_nome()}")
print(f"Preço: R$ {produto.get_preco():.2f}")

# Usando setters
produto.set_nome("Notebook Gamer")
produto.set_preco(3500)

# Aplicando desconto
produto.aplicar_desconto(10)
print(f"Novo preço: R$ {produto.get_preco():.2f}")

Encapsulamento em Python:
Usando Decorators

book_2 Como funciona?

O decorador @property é a forma mais "pythônica" de implementar encapsulamento. Ele permite criar métodos que se comportam como atributos.


book_2 Por que usar?

Quando queremos criar uma propriedade (atributo) que se comporta como um metodo, o decorator @property é uma opção.

book_2 O que é um decorator?

Um decorator em Python é uma função que permite adicionar novas funcionalidades ou modificar o comportamento de outras funções ou métodos sem alterar seu código-fonte original, "embrulhando-as" com uma lógica extra (como logging, controle de acesso, ou medição de tempo) e retornando uma nova função modificada, usando a sintaxe @nome_do_decorator.


book_2 Exemplo simples de decorator:

# Criando o decoratoe "prefixo"
def prefixo(funcao):
    def envelope(texto):
        resultado = funcao(texto)
        if len(resultado) > 5:
            return f"STRING LONGA: {resultado}"
        else:
            return f"STRING CURTA: {resultado}"
    return envelope

@prefixo
def processar_string(texto): # Esta e a função básica
    return texto.upper()

# Testando o decorator
print(processar_string("Olá"))        # Saída: STRING CURTA: Olá
print(processar_string("Olá, mundo")) # Saída: STRING LONGA: Olá, mundo

Você pode criar seus próprios decorators ou utilizar decorators já existentes para criar novos comportamentos.


book_2 Aplicando um decorator @property em POO

Agora vamos aplicar essa ideia para o nosso caso específico.

O decorator @property (que já existe previamente) permite que criemos um getter e um setter para um atributo privado.


book_2 Exemplo @property:

class Produto:
    def __init__(self, nome, preco):
        self.__nome = nome # Atributo privado
        self.__preco = preco
    
    @property
    def nome(self):
        """Getter para o nome"""
        return self.__nome
        # Setter para nome

    @nome.setter
    def nome(self, nome):
        """Setter para o nome com validação"""
        if not nome or len(nome) < 3:
            raise ValueError("Nome deve ter pelo menos 3 caracteres")
        self.__nome = nome
    
    @property
    def preco(self):
        """Getter para o preço"""
        return self.__preco
    
    @preco.setter
    def set_preco(self, preco):
        """Setter para o preço com validação"""
        if preco < 0:
            raise ValueError("Preço não pode ser negativo")
        self.__preco = preco

# ----- Como usar -----

# Criando objeto
pessoa = Pessoa("João", 25)

# Acessando como se fossem atributos normais (usando o getter)
print(pessoa.nome) # João
print(pessoa.idade) # 25

# Modificando com validação automática (usando o setter)
pessoa.nome = "Maria"
pessoa.idade = 30

# Tentativa de atribuir valor inválido (gera erro)
pessoa.idade = -5 # Vai gerar erro!

book_2 Diferença entre @property e get/set

Decorator @property Métodos get/set

Mais "pythônico" Mais explícito
Sintaxe limpa Mais verboso

(também funciona em Python)

book_2 O Conceito de Associação entre Objetos

Associação representa relacionamentos entre objetos de diferentes classes. É quando um objeto "conhece" ou "usa" outro objeto.

book_2 Tipos de associação

  1. Agregação:
    • Relação "tem um" (has-a) fraca
    • Objetos podem existir independentemente
    • Exemplo: Departamento tem Funcionários
  2. Composição:
    • Relação "tem um" (has-a) forte
    • Um objeto não existe sem o outro
    • Exemplo: Casa tem Cômodos
  3. Associação simples:
    • Objetos se relacionam mas não há "propriedade"
    • Exemplo: Professor leciona Disciplinas




book_2 Exemplo de Associação:

class Endereco:
    def __init__(self, rua, numero, cidade):
        self.rua = rua
        self.numero = numero
        self.cidade = cidade
    def __str__(self):
        return f"{self.rua}, {self.numero} - {self.cidade}"

class Pessoa:
    def __init__(self, nome, endereco):
        self.nome = nome
        self.endereco = endereco # Associação: Pessoa tem um Endereço
    def exibir_info(self):
        print(f"Nome: {self.nome}")
        print(f"Endereço: {self.endereco}")

# Criando objetos associados
endereco = Endereco("Av. Paulista", 1000, "São Paulo")
pessoa = Pessoa("João", endereco)
pessoa.exibir_info()

book_2 Cardinalidade

  • 1:1 (um para um): Uma pessoa tem um CPF
  • 1:N (um para muitos): Um autor escreve vários livros
  • N:N (muitos para muitos): Alunos cursam várias disciplinas, disciplinas têm vários alunos

book_2 Projeto: Gerenciamento de Escola

Vamos criar um sistema completo que demonstra encapsulamento e associação entre três classes: Aluno, Turma e Disciplina. O sistema permitirá consultar dados e visualizar os relacionamentos.


book_2 Relacionamentos

  • Uma Disciplina pode ter várias Turmas
  • Uma Turma pertence a uma Disciplina e tem vários Alunos
  • Um Aluno pode estar matriculado em várias Turmas


class Aluno:
    """Representa um aluno com dados encapsulados"""
    def __init__(self, matricula, nome, idade):
        self._matricula = matricula
        self._nome = nome
        self._idade = idade
        self._turmas = [] # Lista de turmas em que está matriculado

    @property
    def matricula(self):
        """Getter para o matrícula"""
        return self._matricula
    
    @property
    def nome(self):
        """Getter para o nome"""
        return self._nome

    @nome.setter
    def nome(self, valor):
        """Setter para o nome"""
        if not valor or not valor.strip():
            raise ValueError("Nome não pode ser vazio")
        self._nome = valor.strip()

    @property
    def idade(self):
        """Getter para o idade"""
        return self._idade

    @idade.setter
    def idade(self, valor):
        """Setter para o idade"""
        if valor < 5 or valor > 100:
            raise ValueError("Idade deve estar entre 5 e 100 anos")
        self._idade = valor

    def adicionar_turma(self, turma):
        """Matricula o aluno em uma turma"""
        if turma not in self._turmas:
            self._turmas.append(turma)

    def listar_turmas(self):
        """Retorna lista de turmas do aluno"""
        return self._turmas.copy()

    def __str__(self):
        return f"{self._nome} (Mat: {self._matricula})"

class Turma:
    """Representa uma turma com alunos e disciplina"""
    def __init__(self, codigo, periodo, disciplina):
        self._codigo = codigo
        self._periodo = periodo
        self._disciplina = disciplina
        self._alunos = []
        self._disciplina.adicionar_turma(self) # Associação bidirecional

    @property
    def codigo(self):
        '''Getter para o codigo'''
        return self._codigo

    @property
    def periodo(self):
        '''Getter para o periodo'''
        return self._periodo

    @property
    def disciplina(self):
        '''Getter para a disciplina'''
        return self._disciplina

    def matricular_aluno(self, aluno):
        """Matricula um aluno na turma"""
        if not isinstance(aluno, Aluno):
            raise TypeError("Apenas objetos do tipo Aluno podem ser matriculados")
        if aluno in self._alunos:
            print(f"Aluno {aluno.nome} já está matriculado nesta turma.")
            return
        self._alunos.append(aluno)
        aluno.adicionar_turma(self)
        print(f"Aluno {aluno.nome} matriculado em {self._disciplina.nome} - {self._codigo}")

    def remover_aluno(self, aluno):
        """Remove um aluno da turma"""
        if aluno in self._alunos:
            self._alunos.remove(aluno)
            print(f"Aluno {aluno.nome} removido da turma {self._codigo}")
        else:
            print(f"Aluno {aluno.nome} não está matriculado nesta turma.")
    
    def listar_alunos(self):
        """Retorna lista de alunos da turma"""
        return self._alunos.copy()

    def quantidade_alunos(self):
        """Retorna o número de alunos matriculados"""
        return len(self._alunos)

    def __str__(self):
        return f"Turma {self._codigo} - {self._periodo}"

class Disciplina:
    """Representa uma disciplina com suas turmas"""
    def __init__(self, codigo, nome, carga_horaria):
        self._codigo = codigo
        self._nome = nome
        self._carga_horaria = carga_horaria
        self._turmas = []

    @property
    def codigo(self):
        '''Getter para o codigo'''
        return self._codigo

    @property
    def nome(self):
        '''Getter para o nome'''
        return self._nome

    @nome.setter
    def nome(self, valor):
        """Setter para o nome"""
        if not valor or not valor.strip():
            raise ValueError("Nome da disciplina não pode ser vazio")
        self._nome = valor.strip()

    @property
    def carga_horaria(self):
        '''Getter para a carga horaria'''
        return self._carga_horaria

    @carga_horaria.setter
    def carga_horaria(self, valor):
        """Setter para a carga horaria"""
        if valor <= 0:
            raise ValueError("Carga horária deve ser positiva")
        self._carga_horaria = valor

    def adicionar_turma(self, turma):
        """Adiciona uma turma à disciplina"""
        if turma not in self._turmas:
        self._turmas.append(turma)

    def listar_turmas(self):
        """Retorna lista de turmas da disciplina"""
        return self._turmas.copy()

    def total_alunos(self):
        """Calcula o total de alunos em todas as turmas"""
        return sum(turma.quantidade_alunos() for turma in self._turmas)

    def __str__(self):
        return f"{self._nome} ({self._codigo}) - {self._carga_horaria}h"

class SistemaEscolar:
    """Sistema para gerenciar e consultar dados da escola"""
    def __init__(self):
        self._disciplinas = []
        self._alunos = []

    def adicionar_disciplina(self, disciplina):
        """Adiciona uma disciplina ao sistema"""
        self._disciplinas.append(disciplina)
        print(f"Disciplina {disciplina.nome} adicionada ao sistema")

    def adicionar_aluno(self, aluno):
        """Adiciona um aluno ao sistema"""
        self._alunos.append(aluno)
        print(f"Aluno {aluno.nome} adicionado ao sistema")

    def exibir_disciplina_completa(self, disciplina):
        """Exibe informações completas de uma disciplina"""
        print(f"\n{'='*60}")
        print(f"DISCIPLINA: {disciplina.nome}")
        print(f"Código: {disciplina.codigo} | Carga Horária: {disciplina.carga_horaria}h")
        print(f"Total de turmas: {len(disciplina.listar_turmas())}")
        print(f"Total de alunos: {disciplina.total_alunos()}")
        print(f"{'='*60}")
        for turma in disciplina.listar_turmas():
            print(f"\n {turma} - {turma.quantidade_alunos()} alunos")
        
    def exibir_aluno_completo(self, aluno):
        """Exibe informações completas de um aluno"""
        print(f"\n{'='*60}")
        print(f"ALUNO: {aluno.nome}")
        print(f"Matrícula: {aluno.matricula} | Idade: {aluno.idade} anos")
        print(f"Total de turmas: {len(aluno.listar_turmas())}")
        print(f"{'='*60}")
        if aluno.listar_turmas():
            print("\nTurmas matriculadas:")
            for i, turma in enumerate(aluno.listar_turmas(), 1):
                print(f" {i}. {turma.disciplina.nome} - {turma.codigo} ({turma.periodo})")
        else:
            print("\nNenhuma turma matriculada ainda.")

    def relatorio_geral(self):
        """Exibe relatório geral do sistema"""
        print(f"\n{'#'*60}")
        print(f"{'RELATÓRIO GERAL DO SISTEMA ESCOLAR':^60}")
        print(f"{'#'*60}")
        print(f"\nTotal de disciplinas: {len(self._disciplinas)}")
        print(f"Total de alunos: {len(self._alunos)}")
        total_turmas = sum(len(d.listar_turmas()) for d in self._disciplinas)
        print(f"Total de turmas: {total_turmas}")
        total_matriculas = sum(len(a.listar_turmas()) for a in self._alunos)
        print(f"Total de matrículas: {total_matriculas}")
        print(f"\n{'#'*60}")
