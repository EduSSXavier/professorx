Dicionário

Um estrutura de dados baseada em chaves

book_2 Definição

Um dicionário em Python é uma estrutura de dados que armazena pares chave-valor (key-value). É uma coleção ordenada (a partir da versão do Python 3.7), mutável e que não permite chaves duplicadas.

Características principais:

  • Chaves únicas: Cada chave pode aparecer apenas uma vez no dicionário.
  • Mutável: Pode ser modificado depois da criação.
  • Indexação por chave: Acesso aos valores aoss chaves.
  • Tipos de dados heterogêneo: Pode armazenar diferentes tipos de dados.

visibility Sintaxe

# Criação de dicionário
dicionario = {chave1: valor1, chave2: valor2, chave3: valor3}

# Dicionário vazio# Dicionário vazio
dicionario_vazio = {}

# ou
dicionario_vazio = dict()

visibility Exemplos de Uso de Dicionários

# Exemplo 1: Informações de uma pessoa ----------------------------
pessoa pessoa ==  {
    "nome": "João Silva",
    "idade": 30,
    "cidade": "São Paulo",
    "profissao": "Programador"
}

# Acessando valores
print(pessoa["nome"])    # João Silva
print(pessoa["idade"])   # 30
print(pessoa["cidade"])  # São Paulo
print(pessoa["profissao"])  # Programador

# Adicionando novo par chave-valor
pessoa["email"] = "joao@email.com"

# Modificando um valor existente
pessoa["idade"] = 31

# Removendo um item
del pessoa["cidade"]


# Exemplo 2: Estoque de produtos ----------------------------
estoque estoque ==  {
    "notebook":  1515,,
    "mouse""mouse"::  5050,,
    "teclado""teclado"::  3030,,
    "monitor""monitor"::  88
}

# Iterando sobre o Dicionário
for produto, quantidade in estoque.items():
    print(f"{produto}: {quantidade} unidades")

# Verificando se uma chave existe
if "notebook" in estoque:
    print("Notebook disponível em estoque")

exercise Exercício 1: Cadastro de Músicas

Objetivo: Vamos criar um sistema de cadastro de músicas usando dicionários.



Requisitos da aplicação:

  • Exibir um menu simples com as opções
    • 1 - Cadastrar uma nova música
    • 2 - Exibir todas as músicas cadastradas
    • 3 - Pesquisar uma musica pelo titulo
    • 4 - Sair
  • As chaves do dicionário devem ser os títulos das músicas
  • Os valores correspondentes aos títulos das músicas devem ser dicionários com as seguintes informações:
    • Intérprete
    • Ano de Lançamento


# Sistema de Cadastro de Músicas

cadastro_musicas = {}

while True:
    print("\n=== CADASTRO DE MÚSICAS ===")
    print("1. Adicionar música")
    print("2. Listar músicas")
    print("3. Buscar música")
    print("4. Sair")
    
    opcao =  input("Escolha uma opção: ")

    if opcao == "1":
        # Solicitando informações
        titulo = input("Digite o título da música: ")
        interprete = input("Digite o intérprete: ")
        ano = int(input("Digite o ano de lançamento: "))

        # Usando o título como chave única
        cadastro_musicas[titulo] =  {
            "interprete": interprete, 
            "ano": ano
        }

        # Exibindo mensagem
        print(f"Música '{titulo}' adicionada com sucesso!"))
    elif opcao == "2":
        # Exibindo o catálogo
        print("\n=== CATÁLOGO DE MÚSICAS ===")
        for titulo, info in cadastro_musicas.items():
            print(f"Título: {titulo}")
            print(f"Intérprete: {info['interprete']}")
            print(f"Ano: {info['ano']}")
            print("-" * 30)
    elif opcao == "3":
        # Buscando uma musica
        titulo =  input("Digite o título da música para buscar: ")
        if titulo in cadastro_musicas:
            info = cadastro_musicas[titulo]
            print(f"\nMúsica encontrada:")
            print(f"Título: {titulo}")
            print(f"Intérprete: {info['interprete']}")
            print(f"Ano: {info['ano']}")
        else:
            print("Música não encontrada.")
    elif opcao == "4":
        # Saindo da aplicação
        print("Encerrando aplicação.")
        break
    else:
        print("Opção inválida! Tente novamente.")

Set

Um conjunto de dados

book_2 Definição

Um set em Python é uma coleção desordenada de elementos únicos. É mutável, mas não permite elementos duplicados e não possui indexação.

Características principais:

  • Elementos únicos: Não permite duplicatas.
  • Desordenado: Não mantém ordem de inserção.
  • Mutável: Pode ser modificado depois da criação.
  • Sem indexação: Não é possivel acessar por índice.
  • Operações matemáticas: Suporta união, interseção, diferença.

visibility Sintaxe

# Criação de set
meu_set =  {elemento1, elemento2, elemento3}

# Set vazio
set_vazio = set() # Note: {} cria um dicionário vazio, não um set

visibility Exemplos de Uso de Sets

# Exemplo 1: Removendo duplicatas de uma lista ----------------------------
numeros_com_duplicatas =  [1, 2, 3, 2, 4, 1, 5, 3]
numeros_unicos = set(numeros_com_duplicatas)
print(numeros_unicos)    # {1, 2, 3, 4, 5}

# Convertendo de volta para lista
lista_sem_duplicatas =  list(numeros_unicos)
print(lista_sem_duplicatas)    # [1, 2, 3, 4, 5]


# Exemplo 2: Operações com Sets ----------------------------
frutas_joao =  {"maçã", "banana", "laranja", "uva"}
frutas_maria =  {"banana" , "kiwi", "laranja", "manga"}

# União (frutas que pelo menos uma pessoa gosta)
todas_frutas = frutas_joao | frutas_maria
# ou 
todas_frutas = frutas_joao.union(frutas_maria)

# Interseção (frutas que ambos gostam)
frutas_comuns = frutas_joao & frutas_maria
# ou 
frutas_comuns = frutas_joao.intersection(frutas_maria)

# Diferença (frutas que apenas João gosta)
frutas_so_joao = frutas_joao - frutas_maria
# ou 
frutas_so_joao = frutas_joao.difference(frutas_maria)


print(f"Todas as frutas: {todas_frutas}")
print(f"Frutas em comum: {frutas_comuns}")
print(f"Frutas só do João: {frutas_so_joao}")

exercise Exercício 2: Controle de Recados

Objetivo: amos criar um sistema de recados usando listas e sets.



Requisitos da aplicação:

  • Exibir um menu simples com as opções
    • 1 - Cadastrar um novo recado
    • 2 - Exibir os recados cadastrados para uma pessoa
    • 3 - Sair
  • Cada recado deve ser armazenado em um set contendo as seguintes informações:
    • Remetente
    • Destinatário
    • Data
    • Mensagem


# Sistema de Controle de Recado

lista_recados = []

while True:
    print("\n=== CADASTRO DE RECADOS ===")
    print("1. Adicionar um novo recado")
    print("2. Listar recados para uma pessoa")
    print("3. Sair")
    
    opcao =  input("Escolha uma opção: ")

    if opcao == "1":
        # Solicitando informações
        remetente = input("Remetente (nome de quem mandou o recado): ")
        destinatario = input("Destinatário (nome de quem recebe o recado): ")
        data = input("Data (dia/mês/ano): ")
        mensagem = input("Mensagem: ")

        # Armazenando o recado em um set
        recado = {"de "+remetente, "para "+destinatario, data, mensagem}
        # Adicionando o recado na lista
        lista_recados.append(recado)

        print("\nRecado cadastrado com sucesso!")   
    elif opcao == "2":
        # Exibindo os recados para uma pessoa

        # Solicitando o nome do destinatario
        destinatario_busca = input("Digite o nome do destinatário: ")

        # Buscando os recados da pessoa informada
        for recado in lista_recados:
            if "para "+destinatario_busca in recado:
                print(f"Recado: {recado}")
        
        print(f"---Fim dos recados para {destinatario_busca}")
    elif opcao == "3":
        # Saindo da aplicação
        print("Encerrando aplicação.")
        break
    else:
        print("Opção inválida! Tente novamente.")

exercise Sistema de Cadastro de Alunos

Objetivo: Crie um programa que cadastre alunos e suas notas usando sicionários e sets.

Requisitos:

  • Usando um loop, cadastre cada aluno informando:
    • Nome do auno
    • 3 notas que o aluno tirou em avaliações
  • O loop deve continuar até que o usuário digite "fim" no nome do aluno
  • Os alunos devem ser armazenados em um dicionário
  • As notas devem ser armazenadas em um set (para cada aluno)
  • Ao final do cadastramento, deve-se exibir os dados de todos os alunos cadastrados antes de encerrar o programa e indicar, ao lado de cada um, se o mesmo foi aprovado (média de notas ≥ 7) ou reprovado.
