Variáveis e Tipos de Dados

Começando do princípio

book_2 Variáveis

Uma variável em Python representa um espaço na memória onde podemos armazenar dados.

visibility Exemplo

a = 5
b = 10
c = a + b

book_2 Tipos de dados

Seu programa python pode armazenar dados em variáveis que podem ser de diferentes tipos. Os principais tipo primitivos são:

  • Strings
  • Números
  • Booleanos

O python permite que se identifique o tipo de dados de uma variável utilizando-se a função type(), o operador isinstance() ou ainda o operador is.

Também é possível mudar o tipo de uma variável com funções de conversão.

visibility Exemplo

# Converter uma string para número decimal
numero1 = float("22.5")

# Converter uma string para número inteiro
numero2 = int("150")

# Converter um número decimal para uma string
texto = str(543)

book_2 Entrada e Saída

Embora seja possível criar e executar programas que funcionam totalmente isoldos, geralmente eles precisam de entrada e saída para se comunicar com o mundo exterior, como o teclado e a tela.

Estruturas Condicionais

Testes e Decisões

book_2 Conceito

Um programa python pode executar diversas tarefas dependendo de uma ou mais condições. Essas condiçoes podem ser testadas de mais de um forma, a depender da situação e do grau de complexidade da aplicação.

book_2 O comando IF e suas variantes

visibility Exemplos

idade = 22

# ----- IF simples -----
if idade >= 18:
    print("Você é maior de idade")

# ----- IF ELSE -----
if idade >= 18:
    print("Você é maior de idade")
else:
    print("Você é menor de idade")

# ----- IF ELIF ELSE -----
if idade >= 18:
    print(" Vocé é maior de idade")
elif idade > 11:
    print(" Vocé é adolescente")
else:
    print(" Vocé é criança")

book_2 O comando MATCH / CASE

A Versão 3.10 da linguagem Python introduziu o comando match e o comando case para validar com condições.

O comando match funciona da mesma forma que o comando if, oferecendo uma estrutura de decisão mais complexa.

Sintaxe:

match expression:
  case x:
    code block
  case y:
    code block
  case _:
    code block

visibility Exemplo

dia = 4
match dia:
  case 1:
    print("Segunda")
  case 2:
    print("Terça")
  case 3:
    print("Quarta")
  case 4:
    print("Quinta")
  case 5:
    print("Sexta")
  case _:
    print("Final de semana")

Estruturas de Repetição

Repetido a execução de blocos de código

book_2 Conceito

Um programa pode executar o mesmo bloco de código diversas vezes. Para isso, usamos o comando while ou for.

O comando while testa uma condição e executa um bloco de código enquanto essa condição for verdadeira.

O comando for executa um bloco de código uma quantidade determinada de vezes.

book_2 O comando WHILE

Sintaxe:

while expressão:
    bloco de código a ser executado

visibility Exemplo

i = 1
while i < 6:
    print(i)
    i += 1

book_2 O comando FOR

Sintaxe:

for variável in sequência:
    bloco de código a ser executado

visibility Exemplos

# -----  sequência é um conjunto de números gerados automaticamente -----
for num in range(10):
  print(num)

# -----  sequência é uma string -----
for letra in "Brasil":
  print(let)

# -----  sequência é uma lista de elementos -----
frutas = ["banana", "maca", "laranja", "pera"]
for f in frutas:
    print(f)

book_2 BREAK e COTINUE

As palavras-chave break e continue podem ser usadas para sair de um loop ou para pular uma parte do loop.

visibility Exemplo

# Exemplo while com break
i = 1
while i < 50:
    if i == 20:
        break
    if i%2 == 0:
        continue
    print(i)
    i += 1

# Exemplo for com continue
for i in range(50):
    if i%2 == 0:
        continue
    print(i)

book_2 Parte 2: Listas

Listas

Agrupando dados em uma sequência

book_2 O Que é uma Lista?

Na linguagem Python, uma lista é uma sequência ordenada de elementos que podem ser modificados e armazenados em memória, em uma única variável.

A estutura de uma lista em Python permite a inclusão e exclusão de elementos em qualquer lugar da sequência, incluindo o inicio e o fim.

visibility Criando Listas

listaNumeros = [1, 2, 3, 4, 5]                  
# ou 
listaNumeros = list((1, 2, 3, 4, 5))

listaFrutas = ["banana", "maca", "laranja"]     
# ou 
listaFrutas = list(("banana", "maca", "laranja"))

listaVazia = []                                 
# ou 
listaVazia = list()

book_2 Índices de Lista

As listas em Python podem ser indexadas, ou seja, acessadas por seus índices, que são numeros inteiros que indicam em que posição um elemento se encontra.

Os índices de uma lista comecam com 0, ou seja, o primeiro elemento está na posição 0, o segundo na posição 1 e assim por diante.

visibility Incluindo novos elementos em listas

listaFrutas = ["banana", "uva", "laranja"] 

# Incluir um novo item no fim da lista
listaFrutas.append("pera")

# Incluir um novo item em uma posição específica
listaFrutas.insert(0, "kiwi")
listaFrutas.insert(1, "abacaxi")

# Incluir um novo item no inicio da lista
listaFrutas.insert(0, "kiwi")

visibility Excluindo elementos de listas

listaFrutas = ["banana", "uva", "laranja"] 

# Excluir um item da lista
listaFrutas.remove("uva")

# Excluir o ultimo item da lista
listaFrutas.pop()

# Excluir o primeiro item da lista
listaFrutas.pop(1)

# Excluir todos os itens da lista
listaFrutas.clear()

visibility Outras manipuações interessantes em listas

listaNumeros = [120, 243,12,3322,78, 114] 

# Criar uma cópia da lista
listaNumerosCopiada = listaNumeros.copy()

# Ordenar a lista
listaNumeros.sort()

# Inverter a ordem da lista
listaNumeros.reverse()

# Contar quantos elementos tem na lista
print(len(listaNumeros))

# Concatenar duas listas
listaNumeros1 = [1,2,3,4]
listaNumeros2 = [5,6,7,8]
listaNumeros3 = listaNumeros1 + listaNumeros2

# Descobrir se um item existe na lista
print(4 in listaNumeros)

# Encontrar o maior e o menor elemento da lista
print(max(listaNumeros))
print(min(listaNumeros))

# Somar todos os elementos da lista
print(sum(listaNumeros))

# Contar quantos vezes um elemento aparece na lista
print(listaNumeros.count(4))

book_2 Parte 3: Tuplas

Tuplas

Uma sequência imutável

book_2 O Que é uma Tupla?

Na linguagem Python, uma tupla é uma sequência ordenada de elementos que não podem ser modificada em uma única variável.

A tupla também é indexada (seus itens podem ser alcançados indicando-se a posição onde estão na tupla).

visibility Criando Tuplas

Para diferenciar uma tupla de uma lista, utilizamos parênteses ao invés de colchetes.

tuplaNumeros = (1, 2, 3, 4, 5)  

tuplaFrutas = ("banana", "uva", "laranja")

tuplaVazia = ()

tuplaComUmElemento = ("banana",)    # note o uso da virgula OBRIGATORIA

tuplaComTiposDiversos = (1, "banana", 3.14, False)

book_2 Índices de Tuplas

As tuplas rambém podem ser indexadas, ou seja, acessadas por seus índices, que são numeros inteiros que indicam em que posição um elemento se encontra.

Os índices de uma tupla comecam com 0, ou seja, o primeiro elemento está na posição 0, o segundo na posição 1 e assim por diante.

visibility Manipuações possíbeis em tuplas

tuplaCarros = ("Fiat", "Honda", "Ford", "Honda")

print(tuplaCarros[0])           # Fiat
print(tuplaCarros[1])           # Honda
print(tuplaCarros[2])           # Ford
print(tuplaCarros[-1])          # Ford
print(tuplaCarros[-2])          # Honda

print(len(tuplaCarros))         # 3

print(tuplaCarros.count("Fiat")) # 1

print(tuplaCarros.index("Honda")) # 2
