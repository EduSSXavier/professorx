Fase 1

O que vamos construir?

book_2 Definição do Projeto

O projeto se propõe aconstruir uma aplicação de cadastro de alunos e notas utilizando dicionários em Python.

O programa deve permitir a inclusão de novos alunos, alteração e exclusão de alunos existentes, a consulta de alunos cadastrados, a atualização de suas notas e relatórios de aprovação.

book_2 O menu principal

O menu principal da aplicação deve permitir ao usuário acessar as diferentes funcionalidades do sistema, como:

  • Cadastro de novos alunos
  • Consulta de alunos cadastrados
  • Exclusão de alunos
  • Atualização de notas
  • Geração de relatórios de aprovação
  • Sair do programa

visibility Dicas:

Para criar o menu, você pode usar um loop WHILE que exibe as opções e solicita a escolha do usuário. Dependendo da opção escolhida, você deve exibir uma mensagem indicando a opção selecionada e retornar ao menu principal.

Para decidir qual funcionalidade executar, use IF/ELSE/ELIF ou MATCH.

Fase 2

Incluindo novos alunos

book_2 Inclusão de Alunos

Substitua a mensagem de inclusão da fase 1 pelas instruções necessárias para incluir um novo aluno.

  • Solicite a matricula do aluno
  • Solicite o nome do aluno
  • Solicite a idade do aluno
  • Atribua ao aluno notas zero para as disciplinas de Matemática, Português e Ciências (pode ser uma lista ou um dicionário)
  • Armazene essas informações em um dicionário
  • Adicione o dicionário a uma lista de alunos


Fase 3

Consultar alunos

book_2 Consulta de Alunos

Substitua a mensagem de consulta da fase 1 pelas instruções necessárias para consultar um aluno.

  • Solicite a matricula do aluno
  • Pesquise o aluno nos dados armazenados
  • Se o aluno for encontrado, exiba suas informações
  • Se o aluno não for encontrado, exiba uma mensagem informando que o aluno não existe




Fase 4

Exclusão de alunos

book_2 Exclusão de Alunos

Substitua a mensagem de exclusão da fase 1 pelas instruções necessárias para excluir um aluno.

  • Solicite a matricula do aluno
  • Pesquise o aluno nos dados armazenados (veja a fase 3)
  • Se o aluno não for encontrado, exiba uma mensagem informando que o aluno não existe
  • Se o aluno for encontrado, exiba suas informações (veja a fase 3)
  • Solicite a confirmação da exclusão
    • Se confirmado, exclua o aluno do dicionário
    • Se confirmado, exiba uma mensagem informando que o aluno foi excluído
    • Retorne ao menu principal

Fase 5

Atualizar notas de alunos

book_2 Atualização das Notas de Alunos

Substitua a mensagem de atualização da fase 1 pelas instruções necessárias para atualizar as notas de um aluno.

  • Pesquise o aluno nos dados armazenados (veja a fase 4)
  • Se o aluno não for encontrado, exiba uma mensagem informando que o aluno não existe (veja a fase 4)
  • Se o aluno for encontrado, exiba suas informações (veja a fase 4)
  • Solicite as novas notas para as disciplinas de Matemática, Português e Ciências
  • Atualize as notas do aluno no dicionário
  • Exiba uma mensagem informando que as notas foram atualizadas

Fase 6

Criar relatórios

book_2 Criação de Relatórios

Substitua a mensagem de atualização da fase 1 pelas instruções necessárias para criar relatórios de alunos.

  • Exibir matrícula, nome, notas, média de notas e situação de aprovação
  • Totalizar alunos aprovados e reprovados
  • Indicar alunos reprovados que podem fazer prova de recuperação (aqueles com média ≥ 5 e < 7)
