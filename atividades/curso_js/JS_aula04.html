book_2 Parte 1: Conceitos

Comando FOR

Apresentando o conceito de loops usando FOR

book_2 Conceito

O laço FOR é uma das estruturas de repetição mais utilizadas em JavaScript. Ele permite executar um bloco de código um número específico de vezes de forma controlada e eficiente.

Repetições Controladas

O laço FOR é ideal quando você sabe exatamente quantas vezes deseja repetir uma operação.

Sintaxe:

for (inicialização; condição; incremento) {
    // código a ser repetido
}

Características:

  • Inicialização: Define uma variável de controle (executada apenas uma vez)
  • Condição: Testada antes de cada iteração (se verdadeira, executa o bloco)
  • Incremento: Executado depois de cada iteração (modifica a variável de controle)

visibility Exemplo

// Imprime números de 1 a 5

for (let i = 1; i <= 5; i++) {
    console.log("Número: " + i);
}

// Saída prevista:

Número: 1
Número: 2
Número: 3
Número: 4
Número: 5

Contadores Usando FOR

Desenvolvendo uma lógica de contagem

book_2 Conceito

Os contadores são variáveis que controlam o número de iterações do laço. Eles podem:

  • Crescer (i++, i += 2)
  • Decrescer (i--, i -= 3)
  • Usar diferentes valores iniciais e finais
  • Ter incrementos/decrementos personalizados

visibility Exemplo

// Contador regressivo de 10 a 1

for (let contador = 10; contador >= 1; contador--) {
    console.log("Contagem regressiva: " + contador);
}

console.log("Fim!");

// Exemplo com incremento de 2 em 2
for (let i = 0; i <= 10; i += 2) {
    console.log("Número par: " + i);
}

// Saída: 0, 2, 4, 6, 8, 10

Estratégias de Uso para o Comando FOR

Combinando o Comando FOR e Estruturas Condicionais

book_2 Conceito

O laço for pode ser combinado com estruturas condicionais ( if , else if , else ) para criar algoritmos mais complexos. Isso permite processar dados de forma seletiva durante as iterações.

visibility Exemplo

/ Conta números pares e ímpares de 1 a 10

let pares = 0;
let impares = 0;

for (let i = 1; i <= 10; i++) {
    if (i % 2 === 0) {
        pares++;
        console.log(i + " é par");
    } else {
        impares++;
        console.log(i + " é ímpar");
    }
}

console.log("Total de pares: " + pares);
console.log("Total de ímpares: " + impares);

Comando FOR ... IN

Executando varredura em objetos

book_2 Conceito

O comando FOR ... IN é uma estrutura de repetição que permite iterar sobre as propriedades de um objeto. Veremos futuramente mais detalhes sobre objetos e como eles podem ser manipulados, mas neste momento, vamos apenas descrever um objeto como um conjunto de um ou mais pares chave-valor e usar o comando FOR ... IN para percorrer os elementos desse conjunto, acessar este objeto e exibir as suas propriedades.

Sintaxe:

for (chave in objeto) {
    // código a ser repetido
}

Características:

  • Chave: Uma variável que recebe o nome de cada chave do objeto ao ser percorrido
  • Objeto: O objeto que será percorrido

visibility Exemplo

let pessoa = {nome:"João", sobrenome:"Silva", idade:25};
let texto = "";

for (let nomeChave in pessoa) {
  texto += pessoa[nomeChave];
}

console.log("Valores concatenados das chaves do objeto: " + texto);

Comando FOR ... OF

Executando varredura em coleções iteráveis

book_2 Conceito

O comando FOR ... OF é uma estrutura de repetição que permite iterar sobre estruturas de dados como Arrays, Strings e outras coleções iteráveis. Isso permite criar algoritmos mais complexos.

Sintaxe:

for (variável of iterável) {
    // código a ser repetido
}

Características:

  • Variável: Uma variável que recebe elemento da coleção percorrida
  • Iterável: O objeto iterável que será percorrido

visibility Exemplo 1 - Varrendo Arrays

const listaDeCarros = ["BMW", "Volvo", "Mini"];

for (let carro of listaDeCarros) {
  console.log(carro);
}

visibility Exemplo 2 - Varrendo Strings

const linguagem = "JavaScript";

for (let letra of listaDeCarros) {
  console.log(letra);
}

Nível Avançado

exercise Exercício

Objetivo: Calcule o fatorial de um número N (exemplo: N = 6).
O fatorial de 6 é 6! = 6 × 5 × 4 × 3 × 2 × 1 = 720.

let n = parseInt(prompt("Digite um número:")); // número para calcular o fatorial
let fatorial = 1;

if (n === 0) {
    fatorial = 1;
} else {
    for (let i = 1; i <= n; i++) {
        fatorial *= i;
        i++;
    }
}

exercise Jogo de Adivinhação de Senha Numérica

Descrição do Desafio: Criar um jogo onde o jogador deve adivinhar uma senha numérica de 3 dígitos. A cada tentativa, o programa deve informar:

  • Quantos dígitos estão nas posições corretas
  • Quantos dígitos fazem parte da senha mas estão em posições erradas
  • Quantos dígitos não fazem parte da senha

Como funciona o jogo:

  1. 1. Inicialização: Define uma senha secreta de 3 dígitos
  2. 2. Loop principal: Usa DO WHILE (lembre-se de mudar isso) para garantir pelo menos uma tentativa
  3. 3. Análise da tentativa: Para cada dígito da tentativa:
    • Verifica se está na posição correta
    • Se não estiver, verifica se existe na senha em outra posição
    • Se não existir, conta como dígito inexistente
  4. 4. Feedback: Informa ao jogador os resultados da análise
  5. 5. Condições de parada: O jogo para quando o jogador acerta ou atinge o limite de 10 tentativas
