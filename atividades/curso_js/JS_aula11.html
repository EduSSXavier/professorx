book_2 O que é o DOM?

Introdução

O que é o DOM?

book_2 Objetivo

O DOM (Document Object Model) é uma interface de programação que representa a estrutura de um documento HTML/XML como uma árvore de objetos. Cada elemento HTML se torna um "nó" que pode ser manipulado via JavaScript.

Conceitos fundamentais:

  • O DOM transforma o HTML em uma estrutura hierárquica de objetos
  • Cada tag HTML é um nó (node) na árvore do DOM
  • O JavaScript pode acessar, modificar, adicionar ou remover esses nós
  • A árvore DOM começa com o objeto document


O DOM é uma parte essencial da programação web, permitindo que os desenvolvedores criem páginas dinâmicas e interativas.

exercise Exemplo:

==== Considere o seguinte documento HTML:

<!DOCTYPE html>
<html>
    <head>
        <title>Minha Página</title>
    </head>
    <body>
        <h1>Título</h1>
        <p>Parágrafo</p>
    </body>
</html>

==== Representação em árvore:

document
  └── html
      ├── head
      │   └── title
      │       └── "Minha Página"
      └── body
          ├── h1
          │   └── "Título"
          └── p
              └── "Parágrafo"

Seleção de Elementos

"Pescando" os elementos da página

book_2 Capturando elementos

Para manipular elementos HTML, primeiro precisamos selecioná-los. JavaScript oferece vários métodos:

getElementById()

Seleciona um elemento pelo seu atributo id.
Retorna um único elemento ou null.

const titulo = document.getElementById('meuTitulo');


getElementsByClassName()

Seleciona todos os elementos com determinada classe.
Retorna uma HTMLCollection (similar a um array).

const itens = document.getElementsByClassName('MinhaClasse');


getElementsByTagName()

Seleciona todos os elementos de uma tag específica.
Retorna uma HTMLCollection.

const paragrafos = document.getElementsByTagName('p');


querySelector()

Seleciona o primeiro elemento que corresponde a um seletor CSS.
Retorna um elemento ou null.

const primeiroItem = document.querySelector('.item');
const linkPrincipal = document.querySelector('#menu a');


querySelectorAll()

Seleciona todos os elementos que correspondem a um seletor CSS.
Retorna uma NodeList (que pode ser tratada como array).

const todosItens = document.querySelectorAll('.item');
const linksMenu = document.querySelectorAll('#menu a');


Diferenças importantes:

  • HTMLCollection vs NodeList: HTMLCollection é "viva" (atualiza automaticamente), enquanto NodeList de querySelectorAll é estática.
  • Seletores: getElementById, getElementsByClassName e getElementsByTagName são específicos, enquanto querySelector e querySelectorAll aceitam qualquer seletor CSS.
  • Retorno: getElementById e querySelector retornam um único elemento, enquanto os outros retornam coleções de elementos.

Modificação de Textos, HTML e Atributos

Alterando sua página

book_2 Alterando elementos

Após selecionar elementos (sim, isso vem primeiro), podemos modificar seu conteúdo e atributos.



book_2 Modificando Texto



textContent

Define ou retorna o texto puro (sem HTML).

const titulo = document.getElementById('meuTitulo');

titulo.textContent = "Novo título";


innerText

Semelhante ao textContent, mas respeita estilos CSS (ex: elementos ocultos).

const titulo = document.getElementById('meuTitulo');

titulo.innerText = "Novo título";


book_2 Modificando HTML



innerHTML

Define ou retorna o conteúdo HTML

elemento.innerHTML = "Texto em negrito";

Atenção: Usar innerHTML pode expor sua aplicação a ataques XSS (Cross-Site Scripting - ataque de injeção de código malicioso) se você inserir conteúdo não confiável.



book_2 Modificando Atributos



getAttribute()

Obtém o valor de um atributo.

const elemento = document.getElementById('meuLink');

const linkCadastro = elemento.getAttribute('href');


setAttribute()

Define o valor de um atributo.

const elemento = document.getElementById('meuLink');

elemento.setAttribute('href', 'https://exemplo.com');


removeAttribute()

Remove um atributo.

const campoEntrda = document.getElementById('meuInputFormulario');

campoEntrda.removeAttribute('disabled');


Acesso direto - Para atributos comuns

elemento.id = "novoId";
elemento.className = "nova-classe";
elemento.src = "imagem.jpg";
elemento.href = "link.html";

Insersão de Novos Elementos

Criando novas tags em sua página

book_2 Criando/Adicionando elementos

Para criar e adicionar novos elementos ao DOM dinamicamente:



createElement() - Cria um novo elemento HTML

appendChild() - Adiciona um elemento como último filho

const divSelecionado = document.getElementById('divPai');

const novoParagrafo = document.createElement('p');

novoParagrafo.innerText = 'Conteúdo do parágrafo';

divSelecionado.appendChild(novoParagrafo);


book_2 Mais Opções



insertBefore() - Insere antes de um elemento de referência

pai.insertBefore(novoElemento, elementoReferencia);


append() - Versão moderna, aceita múltiplos elementos e strings

pai.append(elemento1, "texto", elemento2);


prepend() - Adiciona como primeiro filho

pai.prepend(novoElemento);


book_2 Removendo Elementos



remove() - Remove o próprio elemento

elemento.remove();


removeChild() - Remove um filho específico

pai.removeChild(filho);


book_2 Clonando Elementos



cloneNode() - Clona um elemento

const clone = elemento.cloneNode(true); // true = clona com filhos

Estilização

Formatações dinâmicas

book_2 Estilização

JavaScript permite modificar estilos CSS dinamicamente de várias formas:



Propriedade style

Modifica estilos inline diretamente:

elemento.style.color = "red";
elemento.style.backgroundColor = "yellow"; // OBS: use camelCase
elemento.style.fontSize = "20px";


cssText

Define múltiplos estilos de uma vez:

elemento.style.cssText = "color: red; font-size: 20px;";


book_2 classList (Recomendado)

A melhor prática é usar classes CSS:



elemento.classList.add('classe-estilizada');

elemento.classList.remove('classe-antiga');

elemento.classList.toggle('ativo'); //add + remove

Vantagens de usar classes:
  • Separação de responsabilidades (HTML/CSS/JS)
  • Mais fácil de manter
  • Melhor performance
  • Reutilizável
