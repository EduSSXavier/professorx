Comando WHILE

Apresentando o conceito de loops e o comando WHILE

book_2 Conceito

Os laços de repetição são estruturas fundamentais na programação que permitem executar um bloco de código repetidamente enquanto uma condição específica for verdadeira.

Criação de loops com WHILE

O laço WHILE é uma estrutura de repetição que executa um bloco de código enquanto uma condição for verdadeira. A condição é verificada antes de cada execução do bloco de código.

Sintaxe:

while (condição) {
// código a ser executado
}

Características:

  • Executa o bloco de código enquanto a condição for verdadeira
  • Verifica a condição ANTES de cada execução do bloco
  • Se a condição for falsa, o bloco não é executado
  • É necessário garantir que a condição eventualmente se torne falsa para evitar loops infinitos

visibility Exemplo

// Contagem de 1 a 5

let contador = 1;
while (contador <= 5) {
    console.log("Contagem: " + contador);
    contador++; // Incrementa o contador para evitar loop infinito
}
console.log("Loop finalizado!");

// Saída esperada:

Contagem: 1
Contagem: 2
Contagem: 3
Contagem: 4
Contagem: 5
Loop finalizado!

Comando DO WHILE

E se testarmos depois?

book_2 Conceito

O loop DO WHILE executa o bloco de código primeiro e só depois verifica a condição. Isso garante que o código será executado pelo menos uma vez, mesmo se a condição for falsa desde o início.

Sintaxe:

do {
    // código a ser executado
} while (condição);

Características:

  • O código é executado antes da primeira verificação da condição
  • Garante pelo menos uma execução do bloco de código
  • A condição é verificada ANTES de cada execução
  • Requer modificação de variáveis para evitar loops infinitos

visibility Exemplo

// Uma contagem regressiva:

let numero = 10;
do {
    console.log("Número atual: " + numero);
    numero--;
} while (numero > 5);

console.log("Loop finalizado!");

// Saída:

Número atual: 10
Número atual: 9
Número atual: 8
Número atual: 7
Número atual: 6
Loop finalizado!

Comparação entre WHILE e DO WHILE

Quando é indicado usar?

book_2 Conceito

Quando usar WHILE Quando usar DO WHILE
  • Validação prévia necessária: Quando você precisa verificar a condição antes de executar qualquer parte do código
  • Pode não executar nenhuma vez: Quando você precisa verificar a condição antes de executar qualquer parte do código
  • Leitura de dados com condição de parada: Processamento de listas ou arrays onde você precisa verificar limites de iteração
  • Pelo menos uma execução garantida: Quando você precisa executar o código pelo menos uma vez
  • Menus e interfaces: Exibir opções ao usuário e aguardar escolha
  • Validação de entrada: Solicitar dados do usuário até que sejam válidos

visibility Exemplo de uso ideal para uso de WHILE:

let idade = 15;
while (idade >= 18) {
    console.log("Maior de idade, pode votar!");
    break; // Este código nunca será executado pois 15 > 18
}
console.log("Menor de idade");

visibility Exemplo de uso ideal para uso de DO WHILE:

let opcao;
do {
    console.log("=== MENU ===");
    console.log("1 - Cadastro de vendas");
    console.log("2 - Relatório de vendas");
    console.log("0 - Sair");

    opcao = prompt("Escolha uma opção:"); // Entrada do usuário

    if (opcao === "0") {
        console.log("Você escolheu finalizar o programa.");
    } else if (opcao === "1") {
        console.log("Você escolheu a opção de cadastro de vendas.");
    } else if (opcao === "2") {
        console.log("Você escolheu a opção de relatório de vendas.");
    } else {
        console.log("Opção inválida.");
    }
} while (opcao !== "0");

console.log("Programa finalizado!");

Repetição Baseada em Perguntas

Repetindo até acertar

book_2 Conceito

A simulação de perguntas é um padrão comum onde o programa continua fazendo perguntas ao usuário até que uma condição específica seja atendida. Isso é muito útil para criar interfaces interativas e validar entradas de dados.

visibility Exemplo com WHILE

// Exemplo com WHILE

let continuar = "sim";
let perguntasFeitas = 0;
let resposta

while (continuar === "sim") {
    perguntasFeitas++;
    resposta = prompt("Pergunta " + perguntasFeitas + ": Qual é a capital do Brasil?");

    // Avaliando a resposta do usuário
    if (perguntasFeitas >= 3) {
        continuar = "nao";
    }
}

console.log("Total de perguntas feitas: " + perguntasFeitas);

visibility Exemplo com DO WHILE

// Exemplo com DO WHILE 

let semAcesso = false;
let resposta;
do {
    resposta = prompt("Digite a senha (dica: é '123'): ");

    // Avaliando a resposta do usuário
    if (resposta !== "123") {
        console.log("Senha incorreta! Tente novamente.");
        semAcesso = true; // Sinaliza que o usuário ainda precisa de acesso
    } else {
        semAcesso = false; // Sinaliza que o acesso foi concedido
    }
} while (semAcesso);

console.log("Acesso concedido!");

Exercício 5

Nível Avançado

exercise Exercício

Objetivo: Criar um programa que calcule o fatorial de um número usando WHILE e depois verifique se o resultado é maior que 1000 usando DO WHILE. Em caso afirmativo, fala sucessivas divisões do fatorial por 10 até que este seja menor ou igual a 1000 e informe quantas divisões foram necessárias para conseguir isso.



let numero = 5;
let fatorial = 1;
let contador = numero;

// Calculando o fatorial usando WHILE
while (contador > 0) {
    fatorial = fatorial * contador;
    contador--;
}

console.log("O fatorial de " + numero + " é: " + fatorial);

// Verificando se é maior que 1000 usando DO WHILE
let verificador = fatorial;
let divisoes = 0;
do {
    if (verificador > 1000) {
        console.log("O fatorial é maior que 1000");
        verificador = verificador / 10;
        divisoes++;
    }
} while (verificador > 1000);

console.log("Foram necessárias " + divisoes + " divisões por 10 para ficar <= 1000");

Projeto Prático

Adivinhe a senha

exercise Jogo de Adivinhação de Senha Numérica

Descrição do Desafio: Criar um jogo onde o jogador deve adivinhar uma senha numérica de 3 dígitos. A cada tentativa, o programa deve informar:

  • Quantos dígitos estão nas posições corretas
  • Quantos dígitos fazem parte da senha mas estão em posições erradas
  • Quantos dígitos não fazem parte da senha

Como funciona o jogo:

  1. 1. Inicialização: Define uma senha secreta de 3 dígitos
  2. 2. Loop principal: Usa DO WHILE para garantir pelo menos uma tentativa
  3. 3. Análise da tentativa: Para cada dígito da tentativa:
    • Verifica se está na posição correta
    • Se não estiver, verifica se existe na senha em outra posição
    • Se não existir, conta como dígito inexistente
  4. 4. Feedback: Informa ao jogador os resultados da análise
  5. 5. Condições de parada: O jogo para quando o jogador acerta ou atinge o limite de 10 tentativas

Este desafio combina todos os conceitos aprendidos: loops WHILE e DO WHILE, estruturas condicionais, manipulação de strings e lógica de programação complexa!



// Senha secreta (3 dígitos)
let senhaCorreta = "248";
let tentativa;
let numeroTentativas = 0;
let acertou = false;
let contadorPosicaoCorreta = 0;
let contadorDigitoExiste = 0;
let contadorDigitoNaoExiste = 0;

console.log("=== JOGO DE ADIVINHAÇÃO DE SENHA ===");
console.log("Adivinhe a senha numérica de 3 dígitos!");

do {
    numeroTentativas++;

    tentativa = propmpt("Tentativa " + numeroTentativas + ":");

    if (tentativa === senhaCorreta) {
        acertou = true;
        console.log("PARABÉNS! Você acertou a senha!");
    } else {
        // Análise da tentativa

        // Verificar cada posição
        let i = 0;
        while (i < 3) {
            let digitoTentativa = tentativa[i];
            let digitoSenha = senhaCorreta[i];
            if (digitoTentativa === digitoSenha) {
                // Posição correta
                contadorPosicaoCorreta++;
            } else {
                // Verificar se o dígito existe na senha em outra posição
                let j = 0;
                let encontrou = false;

                while (j lt; 3 && !encontrou) {
                    if (digitoTentativa === senhaCorreta[j] && j !== i) {
                        encontrou = true;
                    }
                    j++;
                }

                if (encontrou) {
                    digitoExiste++;
                } else {
                    digitoNaoExiste++;
                }
            }
    
            i++;
        }

        // Feedback para o jogador - Resultados da análise
        console.log("Resultado da análise:");
        console.log("Dígitos na posição correta: " + posicaoCorreta);
        console.log("Dígitos corretos em posição errada: " + digitoExiste);
        console.log("Dígitos que não existem na senha: " + digitoNaoExiste);
        if (numeroTentativas >= 10) {
            console.log("Você atingiu o limite de tentativas!");
            console.log("A senha correta era: " + senhaCorreta);
            break;
        }
    }
} while (!(acertou && (numeroTentativas < 10)));

if (acertou) {
    console.log("Você completou o desafio em " + numeroTentativas + " tentativas!");
} else {
console.log("Tente novamente na próxima vez!");
}

console.log("\n=== FIM DO JOGO ===");
