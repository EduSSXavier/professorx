🧠 O que é Lógica de Programação?

Definição

Lógica de Programação é a capacidade de organizar pensamentos e instruções de forma sequencial e estruturada para resolver problemas computacionais.

Pensamento Computacional

  • Decomposição: Quebrar problemas complexos em partes menores
  • Reconhecimento de Padrões: Identificar similaridades e tendências
  • Abstração: Focar nos aspectos essenciais, ignorando detalhes desnecessários
  • Algoritmos: Criar sequências de instruções para resolver problemas

📋 Exemplo do Dia a Dia: Fazer um Sanduíche

Problema: Preparar um sanduíche

Decomposição: Separar ingredientes → Preparar pão → Montar → Finalizar

Sequência lógica: Cada passo deve ser executado em ordem específica!

⚙️ Algoritmos

Definição

Um algoritmo é uma sequência finita e bem definida de instruções para resolver um problema ou executar uma tarefa.

Características dos Algoritmos

  • Finitude: Deve ter um fim
  • Clareza: Cada instrução deve ser clara e sem ambiguidade
  • Efetividade: Deve resolver o problema proposto
  • Entrada: Pode ter zero ou mais dados de entrada
  • Saída: Produz pelo menos um resultado

🔄 Exemplo de Fluxograma Simples

INÍCIO
↓
Ler nome do usuário
↓
Exibir "Olá, [nome]!"
↓
FIM

📝 Representação: Pseudocódigo

O que é Pseudocódigo?

É uma forma de representar algoritmos usando linguagem natural estruturada, antes de convertê-los para uma linguagem de programação específica.

Exemplo: Calcular área de um retângulo

ALGORITMO CalcularAreaRetangulo
INÍCIO
    ESCREVER "Digite a largura:"
    LER largura
    ESCREVER "Digite a altura:"
    LER altura
    area ← largura * altura
    ESCREVER "A área é:", area
FIM

Vantagens do Pseudocódigo

  • Independente de linguagem de programação
  • Focado na lógica, não na sintaxe
  • Fácil de entender e modificar
  • Facilita a comunicação entre programadores

📤 Comando print()

Função do print()

O comando print() é usado para exibir informações no console, permitindo que o programa se comunique com o usuário mostrando resultados, mensagens e dados processados.

Sintaxe Básica

print("Sua mensagem aqui")
print(variavel)
print("Texto", variavel, "mais texto")

Exemplos Práticos

# Exibir texto simples
print("Olá, mundo!")

# Exibir variáveis
nome = "Maria"
idade = 25
print("Nome:", nome)
print("Idade:", idade)

# Exibir múltiplos valores
print("Olá", nome, "! Você tem", idade, "anos.")

# Formatação com f-strings (Python 3.6+)
print(f"Olá {nome}! Você tem {idade} anos.")
Dica: O print() é sua principal ferramenta para debug e comunicação com o usuário!

📥 Comando input()

Função do input()

O comando input() é usado para ler dados do usuário via console, permitindo que o programa receba informações e as processe.

Sintaxe e Características

# Sintaxe básica
variavel = input("Mensagem para o usuário: ")

# O input() SEMPRE retorna uma string (texto)
nome = input("Digite seu nome: ")  # Retorna string
print(f"Olá, {nome}!")

Conversão de Tipos (Casting)

# Para números inteiros
idade = int(input("Digite sua idade: "))

# Para números decimais
altura = float(input("Digite sua altura: "))

# Exemplo completo
nome = input("Digite seu nome: ")
idade = int(input("Digite sua idade: "))
altura = float(input("Digite sua altura (em metros): "))

print(f"Nome: {nome}")
print(f"Idade: {idade} anos")
print(f"Altura: {altura}m")
Importante: Sempre converta os dados para o tipo correto antes de fazer cálculos matemáticos!

➕ Exercício 2: Soma de Dois Números

🎯 Objetivo

Desenvolva um programa que peça dois números, realize a soma e exiba o resultado.

➕ Exercício 2: Soma de Dois Números

🎯 Objetivo

Desenvolva um programa que peça dois números, realize a soma e exiba o resultado.

💡 Solução Passo a Passo

# Passo 1: Solicitar o primeiro número
numero1 = float(input("Digite o primeiro número: "))

# Passo 2: Solicitar o segundo número
numero2 = float(input("Digite o segundo número: "))

# Passo 3: Realizar a soma
soma = numero1 + numero2

# Passo 4: Exibir o resultado
print(f"A soma de {numero1} + {numero2} = {soma}")

🎨 Versão com Mais Detalhes

print("=== CALCULADORA DE SOMA ===")

# Entrada de dados
num1 = float(input("Digite o primeiro número: "))
num2 = float(input("Digite o segundo número: "))

# Processamento
resultado = num1 + num2

# Saída formatada
print("-" * 25)
print(f"Número 1: {num1}")
print(f"Número 2: {num2}")
print(f"Soma: {num1} + {num2} = {resultado}")
print("-" * 25)

📤 Exemplo de Execução

Entrada: 15 e 7
Saída: A soma de 15.0 + 7.0 = 22.0

📊 Exercício 3: Média de Três Notas

🎯 Objetivo

Calcule a média de três notas informadas pelo usuário e exiba o resultado.

📊 Exercício 3: Média de Três Notas

🎯 Objetivo

Calcule a média de três notas informadas pelo usuário e exiba o resultado.

💡 Solução Passo a Passo

nota1 = float(input("Digite a primeira nota: "))

🌡️ Exercício 4: Conversão de Temperatura

🎯 Objetivo

Converta uma temperatura de Celsius para Fahrenheit usando a fórmula: F = (C × 9/5) + 32

🌡️ Exercício 4: Conversão de Temperatura

🎯 Objetivo

Converta uma temperatura de Celsius para Fahrenheit usando a fórmula: F = (C × 9/5) + 32

💡 Solução Passo a Passo

# Passo 1: Solicitar temperatura em Celsius
celsius = float(input("Digite a temperatura em Celsius: "))

# Passo 2: Aplicar a fórmula de conversão
fahrenheit = (celsius * 9/5) + 32

# Passo 3: Exibir o resultado
print(f"{celsius}°C equivale a {fahrenheit}°F")

🏆 Desafio: Calcular Idade

🎯 Desafio

Crie um programa que solicite o ano de nascimento do usuário e calcule sua idade atual (considere o ano atual como 2024).

🏆 Desafio: Calcular Idade

🎯 Desafio

Crie um programa que solicite o ano de nascimento do usuário e calcule sua idade atual (considere o ano atual como 2024).

💡 Solução do Desafio

# Definir o ano atual
ano_atual = 2024

# Solicitar ano de nascimento
ano_nascimento = int(input("Digite seu ano de nascimento: "))

# Calcular a idade
idade = ano_atual - ano_nascimento

# Exibir resultado
print(f"Você tem {idade} anos em {ano_atual}!")
