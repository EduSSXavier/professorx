🤔 O que são Condicionais?

Definição

Condicionais são estruturas de controle que permitem que um programa tome decisões baseadas em condições específicas.

Por que são importantes?

  • Tomada de Decisão: Permitem que programas respondam de forma diferente a situações diferentes
  • Controle de Fluxo: Determinam qual código será executado
  • Lógica de Negócio: Implementam regras e validações
  • Interatividade: Criam programas que respondem às ações do usuário

💡 Exemplo do Dia a Dia

"Se está chovendo, então levo guarda-chuva, senão saio sem guarda-chuva"

Esta é uma decisão condicional que fazemos naturalmente!

🔀 Estrutura Condicional IF

Sintaxe Básica

if condição:
    # código a ser executado
    # se a condição for verdadeira

Características:

  • Sempre termina com :
  • Código indentado (4 espaços)
  • Executa apenas se condição for True

Exemplo Prático

idade = 18
if idade >= 18:
    print("Você é maior de idade")
    print("Pode dirigir!")

Resultado: Como idade = 18 e 18 >= 18 é True, as duas mensagens serão exibidas.

⚖️ Estrutura IF-ELSE

Sintaxe

if condição:
    # código se TRUE
else:
    # código se FALSE

Quando usar:

  • Quando há duas opções mutuamente exclusivas
  • Para garantir que sempre uma ação seja executada
  • Situações de "ou isso ou aquilo"

Exemplo

temperatura = 25

if temperatura > 30:
    print("Está muito quente!")
    print("Vou ligar o ar condicionado")
else:
    print("Temperatura agradável")
    print("Não preciso de ar condicionado")

Resultado: Como 25 não é > 30, executa o bloco else.

🎯 Estrutura ELIF (Else If)

Sintaxe Completa

if primeira_condição:
    # código para primeira condição
elif segunda_condição:
    # código para segunda condição
elif terceira_condição:
    # código para terceira condição
else:
    # código se nenhuma condição for verdadeira

Exemplo: Sistema de Notas

nota = 85

if nota >= 90:
    print("Conceito A - Excelente!")
elif nota >= 80:
    print("Conceito B - Muito Bom!")
elif nota >= 70:
    print("Conceito C - Bom")
elif nota >= 60:
    print("Conceito D - Regular")
else:
    print("Conceito F - Insuficiente")

Resultado: "Conceito B - Muito Bom!" (pois 85 >= 80)

⚖️ Operadores de Comparação

Lista Completa

  • == Igual a
  • != Diferente de
  • < Menor que
  • > Maior que
  • <= Menor ou igual
  • >= Maior ou igual

Exemplos

# Comparações numéricas
print(5 == 5)    # True
print(5 != 3)    # True
print(10 > 7)    # True
print(4 <= 4)    # True

# Comparações de strings
nome = "Ana"
print(nome == "Ana")     # True
print(nome != "João")    # True

⚠️ Cuidado!

Use == para comparar (não =)

= é para atribuir valores!

🧠 Operadores Lógicos

AND - E lógico

Ambas condições devem ser verdadeiras

idade = 20
renda = 3000

if idade >= 18 and renda >= 2000:
    print("Aprovado para empréstimo")

OR - OU lógico

Pelo menos uma condição deve ser verdadeira

dia = "sábado"

if dia == "sábado" or dia == "domingo":
    print("É final de semana!")

NOT - NÃO lógico

Inverte o valor da condição

chuva = False

if not chuva:
    print("Vou sair sem guarda-chuva")

Combinações

idade = 25
estudante = True
renda = 1500

if (idade >= 18 and renda >= 2000) or estudante:
    print("Elegível para desconto")

🪆 Aninhamento de Condicionais

O que é Aninhamento?

É colocar uma estrutura condicional dentro de outra, criando decisões mais complexas.

Exemplo: Sistema de Acesso

usuario_valido = True
senha_correta = True
conta_ativa = True

if usuario_valido:
    print("Usuário encontrado")
    
    if senha_correta:
        print("Senha correta")
        
        if conta_ativa:
            print("Acesso liberado!")
            print("Bem-vindo ao sistema")
        else:
            print("Conta inativa. Contate o suporte")
    else:
        print("Senha incorreta")
        print("Tente novamente")
else:
    print("Usuário não encontrado")

💡 Dica

Use aninhamento quando a segunda condição só faz sentido se a primeira for verdadeira.

🏃‍♂️ Exercício 1: Par ou Ímpar

Objetivo:

Criar um programa que verifica se um número é par ou ímpar

💡 Conceito

Um número é par quando é divisível por 2 (resto da divisão = 0)

Usamos o operador % (módulo) para encontrar o resto

Exemplos:

  • 8 % 2 = 0 (par)
  • 7 % 2 = 1 (ímpar)
  • 10 % 2 = 0 (par)

💻 Solução

numero = int(input("Digite um número: "))

if numero % 2 == 0:
    print(f"{numero} é PAR")
else:
    print(f"{numero} é ÍMPAR")

Teste:

Entrada: 15

Saída: "15 é ÍMPAR"

🗳️ Exercício 2: Verificar Idade para Votar

Objetivo:

Verificar se uma pessoa pode votar baseado na idade (>= 16 anos no Brasil)

📋 Regras no Brasil

  • 16-17 anos: Voto facultativo
  • 18-69 anos: Voto obrigatório
  • 70+ anos: Voto facultativo
  • < 16 anos: Não pode votar

💻 Solução

idade = int(input("Digite sua idade: "))

if idade < 16:
    print("Não pode votar")
elif idade < 18:
    print("Voto facultativo")
elif idade < 70:
    print("Voto obrigatório")
else:
    print("Voto facultativo")

🧪 Testes

Idade 15: "Não pode votar"

Idade 17: "Voto facultativo"

Idade 25: "Voto obrigatório"

Idade 75: "Voto facultativo"

📐 Exercício 3: Classificar Triângulos (Parte 1)

Objetivo:

Verificar se três lados podem formar um triângulo

📏 Regra Fundamental

Para três lados formarem um triângulo:

  • A soma de dois lados deve ser maior que o terceiro
  • Isso deve ser válido para todas as combinações

Exemplo:

Lados: 3, 4, 5

  • 3 + 4 = 7 > 5 ✓
  • 3 + 5 = 8 > 4 ✓
  • 4 + 5 = 9 > 3 ✓

Resultado: É um triângulo!

💻 Verificação

a = float(input("Lado A: "))
b = float(input("Lado B: "))
c = float(input("Lado C: "))

if (a + b > c) and (a + c > b) and (b + c > a):
    print("Os lados formam um triângulo!")
    # Próximo slide: classificar tipo
else:
    print("Os lados NÃO formam um triângulo")

📐 Exercício 3: Tipos de Triângulo (Parte 2)

Se formar um triângulo, qual o tipo?

📚 Classificação

  • Equilátero: 3 lados iguais
  • Isósceles: 2 lados iguais
  • Escaleno: 3 lados diferentes

💻 Solução Completa

a = float(input("Lado A: "))
b = float(input("Lado B: "))
c = float(input("Lado C: "))

if (a + b > c) and (a + c > b) and (b + c > a):
    print("✓ Forma um triângulo!")
    
    if a == b == c:
        print("Tipo: EQUILÁTERO")
    elif a == b or a == c or b == c:
        print("Tipo: ISÓSCELES")
    else:
        print("Tipo: ESCALENO")
else:
    print("✗ NÃO forma um triângulo")

🧪 Teste

Entrada: 3, 3, 4

Saída: "✓ Forma um triângulo!" e "Tipo: ISÓSCELES"

🚀 DESAFIO: Sistema de Login

Implemente um sistema de login simples que verifique usuário e senha

📋 Requisitos

  • Usuário válido predefinido
  • Verificar usuário existe
  • Verificar senha correta
  • Mensagens informativas

💻 Solução

usuario_correto = "admin" 
senha_correta = "123456"

usuario = input("Usuário: ")
senha = input("Senha: ")

if usuario == usuario_correto:
    if senha == senha_correta:
        print(f"Login realizado com sucesso!")
        print(f"Bem-vindo, {usuario}!")
        break
    else:
        print("Senha incorreta")
else:
    print("Usuário incorreto")

🚀 Parte 3: Projeto Incremental

📋 Projeto - Sistema de Gerenciamento de Tarefas Simples (Parte 2):

Modifique o programa da Aula 1 para permitir que o usuário marque uma tarefa como concluída ou não concluída.

🎯 Objetivos do Projeto

  • Peça ao usuário para inserir o nome da tarefa.
  • Após adicionar a tarefa, pergunte se a tarefa está concluída (S/N).
  • Armazene essa informação e exiba o status junto com o nome da tarefa.

Exemplo de saída: Tarefa: Estudar Python - Status: Pendente

📝 Versão Anterior

# Sistema de Gerenciamento de Tarefas
print("=== SISTEMA DE TAREFAS ===")

# Solicitar nome da tarefa
nome_tarefa = input("Digite o nome da tarefa: ")

# Confirmar adição da tarefa
print(f"Tarefa '{nome_tarefa}' adicionada com sucesso!")

💻 Implementação do Projeto

📝 Versão Atualizada

# Sistema de Gerenciamento de Tarefas - Versão Atualizada
print("=== SISTEMA DE TAREFAS ===")

# Solicitar nome da tarefa
nome_tarefa = input("Digite o nome da tarefa: ")

# Solicitar status da tarefa
status_tarefa = input("A tarefa está concluída? (S/N): ")

# Teste para verificar se a tarefa foi concluida
if status_tarefa.upper() == "S":
    status_tarefa_verificada = "Concluída"
else:
    status_tarefa = "Pendente"

# Confirmar adição da tarefa
print(f"Tarefa '{nome_tarefa}' adicionada com sucesso!")
print(f"Status: {status_tarefa_verificada}")
