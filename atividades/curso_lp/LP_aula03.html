O que são Loops?

Definição

Loops (Laços de Repetição) são estruturas que permitem executar um bloco de código repetidamente enquanto uma condição for verdadeira.

Importância da Repetição em Algoritmos

  • Eficiência: Evita escrever o mesmo código várias vezes
  • Flexibilidade: Permite processar quantidades variáveis de dados
  • Automatização: Executa tarefas repetitivas automaticamente
  • Escalabilidade: Funciona com 10 ou 10.000 itens

Exemplo Prático

Imagine que você precisa imprimir "Olá!" 100 vezes. Sem usar loops, você precisaria escrever 100 linhas de código. Usando loops, apenas 3 linhas!

Loop While: Sintaxe e Funcionamento

Sintaxe

while condição:
# bloco de código
# que será repetido

Como Funciona

  • Avalia a condição
  • Se verdadeira: executa o bloco e volta para o passo 1
  • Se falsa: sai do loop

Exemplo Simples

contador = 1
while contador <= 5:
    print(f"Contagem: {contador}")
    contador = contador + 1
print("Fim!")

Saída:

Contagem: 1
Contagem: 2
Contagem: 3
Contagem: 4
Contagem: 5
Fim!

Condição de Parada

O que é?

A condição de parada é a expressão booleana que determina quando o loop deve terminar.

Características Importantes

  • Deve ser uma expressão que retorna True ou False
  • Deve eventualmente se tornar False (senão o loop será infinito)
  • É verificada ANTES de cada execução do bloco

Exemplos de Condições

# Contador
while contador < 10:
    # código
    contador += 1
                    
# Entrada do usuário
resposta = ""
while resposta != "sair":
    # código
    resposta = input("Digite: ")
                    
# Condição complexa
while x > 0 and y < 100:
    # código
    x -= 1
    y += 5

Contadores e Acumuladores

Contadores

Variáveis que contam quantas vezes algo aconteceu.

Exemplo Simples

contador = 0
while contador < 5:
    print("Executando...")
    contador += 1  # Incrementa
print(f"Executou {contador} vezes")

Padrões Comuns

  • contador += 1 (incrementa)
  • contador -= 1 (decrementa)
  • contador += 2 (pula de 2 em 2)

Acumuladores

Variáveis que acumulam valores ao longo das iterações.

Exemplo Simples

soma = 0
numero = 1
while numero <= 100:
    soma += numero  # Acumula
    numero += 1
    
print(f"Soma: {soma}")

Tipos de Acumuladores

  • Soma: soma += valor
  • Produto: produto *= valor
  • Concatenação: texto += palavra

Loops Infinitos

Loop Infinito

Quando a condição nunca se torna False, o programa fica "preso" executando o loop eternamente.

❌ Como Identificar

# ERRO: condição nunca muda
contador = 1
while contador <= 5:
    print(contador)
    # Esqueceu de incrementar!
    
# ERRO: condição nunca se torna False
while True:
    print("Infinito...")
    # Sem break ou mudança na condição

✅ Como Evitar

# CORRETO: modifica a condição
contador = 1
while contador <= 5:
    print(contador)
    contador += 1  # Incrementa!
    
# CORRETO: usa break quando necessário
while True:
    entrada = input("Digite algo: ")
    if entrada == "sair":
        break  # Sai do loop

Dica Importante

Sempre verifique se a variável da condição está sendo modificada dentro do loop!

Comandos Break e Continue

Definição

Comandos especiais que alteram o fluxo de execução dentro de loops.

Exemplos



🛑 Break

Interrompe completamente a execução do loop.

contador = 1
while contador <= 10:
    if contador == 6:
        break  # Sai do loop
    print(contador)
    contador += 1
print("Fim")

# Saída: 1, 2, 3, 4, 5, Fim


⏭️ Continue

Pula para a próxima iteração, ignorando o resto do código.

contador = 0
while contador < 5:
    contador += 1
    if contador == 3:
        continue  # Pula para próxima
    print(contador)

# Saída: 1, 2, 4, 5


Exemplo Prático: Validação de Entrada

while True:
    idade = input("Digite sua idade (ou 'sair' para terminar): ")
    
    if idade == 'sair':
        break  # Sai do programa
    
    if not idade.isdigit():
        print("Por favor, digite apenas números!")
        continue  # Volta para o início
    
    idade = int(idade)
    print(f"Você tem {idade} anos.")
    break  # Entrada válida, sai do loop

Exercício 1: Números de 1 a 10

🎯 Desafio

Passo a Passo

Exercício 2: Soma de 1 a N

🎯 Desafio

Calcule a soma dos números de 1 a N, onde N é fornecido pelo usuário.

Análise do Problema

  • Precisamos de um acumulador para a soma
  • Precisamos de um contador para os números
  • A entrada N define até onde contar

Variáveis Necessárias

  • n: número fornecido pelo usuário
  • soma: acumulador (inicia em 0)
  • numero: contador (inicia em 1)

💡 Solução

n = int(input("Digite um número: "))
soma = 0
numero = 1

while numero <= n:
    soma += numero
    numero += 1

print(f"A soma dos números de 1 a {n} é {soma}.")

Exemplo de Execução:

Digite um número: 5
A soma de 1 a 5 é: 15

1 + 2 + 3 + 4 + 5 = 15

Exercício 3: Jogo de Adivinhação

🎯 Desafio

Implemente um jogo onde o usuário tenta adivinhar um número secreto.

💡 Solução Completa

import random

# Gerar número secreto
numero_secreto = random.randint(1, 100)
tentativas = 0

print("=== JOGO DE ADIVINHAÇÃO ===")
print("Tente adivinhar o número entre 1 e 100!")

while True:
    # Receber palpite do usuário
    palpite = int(input("Digite seu palpite: "))
    tentativas += 1
    
    # Verificar palpite
    if palpite == numero_secreto:
        print(f"🎉 Parabéns! Você acertou em {tentativas} tentativas!")
        break
    elif palpite < numero_secreto:
        print("📈 Muito baixo! Tente um número maior.")
    else:
        print("📉 Muito alto! Tente um número menor.")

print("Obrigado por jogar!")

Conceitos Utilizados

  • Loop infinito com break
  • Contador de tentativas
  • Condicionais aninhadas
  • Módulo random para gerar números

Exercício 4: Soma até Digitar 0

🎯 Desafio

Peça números ao usuário até que ele digite 0, então exiba a soma de todos.

Estratégia

  1. Inicializar soma = 0
  2. Loop infinito
  3. Pedir número ao usuário
  4. Se 0: quebrar o loop
  5. Senão: somar ao total
  6. Exibir resultado

💡 Solução

soma = 0
print("Digite números para somar.")
print("Digite 0 para terminar.")

while True:
    numero = float(input("Número: "))
    
    if numero == 0:
        break
    
    soma += numero

print(f"Soma total: {soma}")

Exemplo de Execução:

Digite números para somar.
Digite 0 para terminar.
Número: 10
Número: 5
Número: 3
Número: 0
Soma total: 18.0

Exercício 5:
Calculadora com Menu Interativo

🎯 Desafio

Crie um menu interativo onde o usuário escolhe opções até decidir sair.

while True:
    print("\n=== CALCULADORA SIMPLES ===")
    print("1. Somar")
    print("2. Subtrair") 
    print("3. Multiplicar")
    print("4. Dividir")

        print("Obrigado por usar a calculadora!")
        break

        a = float(input("Primeiro número: "))
        b = float(input("Segundo número: "))
        
        if opcao == "1":
            print(f"Resultado: {a + b}")
        elif opcao == "2":
            print(f"Resultado: {a - b}")
        elif opcao == "3":
            print(f"Resultado: {a * b}")
        elif opcao == "4":
            if b != 0:
                print(f"Resultado: {a / b}")
            else:
                print("Erro: Divisão por zero!")
        else:
            print("Opção inválida!")
