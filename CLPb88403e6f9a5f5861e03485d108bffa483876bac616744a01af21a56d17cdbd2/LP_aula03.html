Executando diversas vezes um bloco de código

O que são Loops?

Loops (Laços de Repetição) são estruturas que permitem executar um bloco de código repetidamente enquanto uma condição for verdadeira.


Importância da Repetição em Algoritmos

  • Eficiência: Evita escrever o mesmo código várias vezes
  • Flexibilidade: Permite processar quantidades variáveis de dados
  • Automatização: Executa tarefas repetitivas automaticamente
  • Escalabilidade: Funciona com 10 ou 10.000 itens

Exemplo Prático

Imagine que você precisa imprimir "Olá!" 100 vezes. Sem usar loops, você precisaria escrever 100 linhas de código. Usando loops, apenas 3 linhas!

Loop While: Sintaxe e Funcionamento

Sintaxe Básica

while condição:
    # bloco de código
    # que será repetido

Como Funciona

Loops WHILE são estruturas que permitem executar um bloco de código repetidamente enquanto uma condição for verdadeira.

  1. Avalia a condição
  2. Se verdadeira: executa o bloco e volta para o passo 1
  3. Se falsa: sai do loop

Exemplo Simples

contador = 1
while contador <= 5:
    print(f"Contagem: {contador}")
    contador = contador + 1
print("Fim!")

Saída:

Contagem: 1
Contagem: 2
Contagem: 3
Contagem: 4
Contagem: 5
Fim!

Condição de Parada

O que é?

A condição de parada é a expressão booleana que determina quando o loop deve terminar.

Características Importantes

  • Deve ser uma expressão que retorna True ou False
  • Deve eventualmente se tornar False (senão o loop será infinito)
  • É verificada ANTES de cada execução do bloco

Exemplo: Controlando um Contador

  contador = 0
  while contador < 10:
      # código a ser executado
      contador += 1

Exemplo: Testando uma Entrada do Usuário

  resposta = ""
  while resposta != "sair":
      # código a ser executado
      resposta = input("Digite: ")


Exemplo: Usando uma Condição complexa

  x = 10
  y = 0
  while x > 0 and y < 100:
      # código a ser executado
      x -= 1
      y += 5

Contadores

Variáveis que contam quantas vezes algo aconteceu.

Exemplo Simples:

contador = 0
while contador < 5:
  print("Executando...")
  contador += 1  # Incrementa
print(f"Executou {contador} vezes")

Padrões Comuns

  • contador += 1 (incrementa)
  • contador -= 1 (decrementa)
  • contador += 2 (pula de 2 em 2)

Acumuladores

Variáveis que acumulam valores ao longo das iterações.

Exemplo Simples

soma = 0
numero = 1
while numero <= 10:
    soma += numero  # Acumula
    numero += 1
    
print(f"Soma: {soma}")

Tipos de Acumuladores

  • Soma: soma += valor
  • Produto: produto *= valor
  • Concatenação: texto += palavra

Exercício 1: Contagem

Crie um programa que imprima os números de 1 a 100 usando o comando while.

Passo a Passo

  1. Inicializar uma variável contador
  2. Definir a condição do while
  3. Imprimir o número atual
  4. Incrementar o contador

Dicas

  • Comece o contador em 1
  • Continue enquanto <= 100
  • Não esqueça de incrementar!
# Programa:

contador = 1
while contador <= 100:
    print(contador)
    contador += 1

Crie um programa que calcule a soma de todos os números ímpares entre 1 e 100. O programa deve exibir a soma final e quantos números foram somados.

Dicas

Agora você precisa contar e acumular, por isso vai recisar de duas variáveis (uma para cada tarefa)

numero = 1

Loops Infinitos

Quando a condição de parada nunca se torna falsa (False), o programa fica "preso", executando o loop eternamente.

Como Identificar?

# ERRO: condição nunca muda

contador = 1
while contador <= 5:
    print(contador)
    # Esqueceu de incrementar!
    

# ERRO: condição nunca se torna False

while True:
    print("Infinito...")
    # Sem break ou mudança na condição

Como Evitar?

# CORRETO: modificar a condição

contador = 1
while contador <= 5:
  print(contador)
  contador += 1  # Incrementa!

Dica Importante

Sempre verifique se a variável da condição está sendo modificada dentro do loop!

Comandos break e continue

Comandos especiais que alteram o fluxo de execução dentro de loops.


Break

Interrompe completamente a execução do loop.

contador = 1
while contador <= 10:
    if contador == 6:
        break  # Sai do loop
    print(contador)
    contador += 1
print("Fim")

# Saída: 1, 2, 3, 4, 5, Fim

Continue

Pula para a próxima iteração, ignorando o resto do código.

contador = 0
while contador < 5:
    contador += 1
    if contador == 3:
        continue  # Pula para próxima iteração
    print(contador)

# Saída: 1, 2, 4, 5

Exemplo Prático: Validação de Entrada

while True:
    idade = input("Digite sua idade (ou 'sair' para terminar): ")
    
    if idade == 'sair':
        break  # Sai do programa
    
    if not idade.isdigit():
        print("Por favor, digite apenas números!")
        continue  # Volta para o início
    
    idade = int(idade)
    print(f"Você tem {idade} anos.")
    break  # Entrada válida, sai do loop

Projeto - Calculadora


Crie uma calculadora que realiza as quatro operações aritméticas básicas (soma, subtração, multiplicação e divisão) com um menu interativo onde o usuário escolhe as operações até decidir sair.


Para cada operação selecionada, solicite também ao usuário dois números para serem utilizados no calculo.


Na operação de divisão, não permita que sejam feitas divizões por zero.


  while True:
      print("\n=== CALCULADORA SIMPLES ===")
      print("1. Somar")
      print("2. Subtrair") 
      print("3. Multiplicar")
      print("4. Dividir")
      print("0. Sair")
      
      opcao = input("Escolha uma opção: ")
      
      if opcao == "0":
          print("Obrigado por usar a calculadora!")
          break
      else:    
          a = float(input("Primeiro número: "))
          b = float(input("Segundo número: "))
          
          if opcao == "1":
              print(f"Resultado: {a + b}")
          elif opcao == "2":
              print(f"Resultado: {a - b}")
          elif opcao == "3":
              print(f"Resultado: {a * b}")
          elif opcao == "4":
              if b != 0:
                  print(f"Resultado: {a / b}")
              else:
                  print("Erro: Divisão por zero!")
          else:
              print("Opção inválida!")
