O Comando FOR

O laço for em Python é uma estrutura de repetição que permite iterar sobre sequências (listas, strings, ranges, etc.).


Sintaxe Básica

for variavel in sequencia:
    # código a ser executado

Características principais:

  • A variável assume cada valor da sequência a cada iteração
  • O bloco de código é executado para cada elemento
  • A indentação define o escopo do laço

Exemplo Básico

# Iterando sobre uma string
for letra in "Python":
  print(letra)

# Saída: P, y, t, h, o, n
# (cada letra em uma linha)

Uso da Função range()

A função range() é fundamental para criar sequências numéricas controladas:

Sintaxes de Range()

range(stop)               # De 0 até stop-1

range(start, stop)        # De start até stop-1

range(start, stop, step)  # De start até stop-1, com passo step

Exemplos Práticos

# range(5) → 0, 1, 2, 3, 4

for i in range(5):
    print(i)


# range(2, 8) → 2, 3, 4, 5, 6, 7

for i in range(2, 8):
    print(i)


# range(0, 10, 2) → 0, 2, 4, 6, 8

for i in range(0, 10, 2):
    print(i)

Comparação entre WHILE e FOR


Aspecto WHILE FOR
Uso principal Repetição com condição Iteração sobre sequências
Controle Manual (contador próprio) Automático
Sintaxe Mais verbosa Mais concisa
Risco Loop infinito se mal usado Mais seguro
Conclusão Repetição com condição. Mais direto para iterar sobre coleções ou intervalos.

Exemplo comparativo: Contar de 1 a 5

# Com WHILE

contador = 1
while contador <= 5:
    print(contador)
    contador += 1


# Com FOR (mais simples)

for contador in range(1, 6):
    print(contador)

Quando usar cada um:

  • WHILE: Quando a condição de parada for conhecida, mas o momento em que essa condição vai ocorrer for desconhecido.
  • FOR: Quando o conjunto de elementos a serem iterados for conhecido (a condição de parada torna=se o final do conjunto).

Manipulação de Listas


Listas em Python

Listas são coleções ordenadas e mutáveis, permitindo armazenar múltiplos itens em uma única variável.


Conceitos fundamentais para listas:

# Criando uma lista vazia
lista_nomes = []

# Adicionando elementos
lista_nomes.append("João")
lista_nomes.append("Maria")

# Iterando sobre a lista
for nome in lista_nomes:
    print(f"Nome cadastrado: {nome}")

# Acessando elementos por índice
for i in range(len(lista_nomes)):
    print(f"Posição {i}: {lista_nomes[i]}")

Operações básicas com FOR e listas:

# Preenchendo uma lista com FOR
numeros = []
for i in range(1, 6):
    numeros.append(i * 2)
print(numeros)  # [2, 4, 6, 8, 10]


# Processando dados de uma lista
vendas = [100, 250, 180, 300, 90]
total = 0
for venda in vendas:
    total += venda
media = total / len(vendas)
print(f"Média de vendas: {media}")

Importante:

  • Listas são coleções mutáveis, permitindo adição, remoção e modificação de elementos, oferecendo, inclusive, mais de uma maneira de realizar essas operações.
  • Porém, neste módulo, nosso foco é apenas a manipulação de dados usando o comando FOR. Por isso estamos mostrando apenas o uso básico de listas.
  • Em aulas futuras, no módulo de programação de linguagem Python, abordaremos outros aspectos das listas e todo o seu potencial.

Exercício 5: Desafio


Cadastro de Notas e Média

Cadastrar notas em uma lista e calcular a média aritmética e indicar qual a maior e qual a menor nota informadas.

Dica:

  • Utilize um laço while para coletar as notas.
  • Utilize um laço for para contar e avaliar as notas.
cadastro_notas = []

print("=== CADASTRO DE NOTAS ===")
print("Digite as notas (0 a 10) ou 'fim' para encerrar./n")

# Coletando as notas
while True:
    entrada = input(f"Nota: ")
    
    if entrada.lower() == 'fim':
        break
    
    nota = float(entrada)
    if 0 <= nota <= 10:
        cadastro_notas.append(nota)
    else:
        print("Nota deve estar entre 0 e 10!")

# Calculando e exibindo resultados
print("="*40))
print("RELATÓRIO DE NOTAS")
print("="*40)

soma = 0
quantidade = 0
nota_maxima = 0
nota_minima = 10

for nota in cadastro_notas:
    soma += nota
    quantidade += 1

    if nota > nota_maxima:
        nota_maxima = nota
    if nota < nota_minima:
        nota_minima = nota

media = soma / quantidade

print(f"\nEstatísticas:")
print(f"  Quantidade de notas: {quantidade}")
print(f"  Soma das notas: {soma}")
print(f"  Média aritmética: {media:.2f}")
print(f"  Maior nota: {nota_maxima}")
print(f"  Menor nota: {nota_minima}")
