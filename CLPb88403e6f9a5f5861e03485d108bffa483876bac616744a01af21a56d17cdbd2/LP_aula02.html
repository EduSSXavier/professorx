Estuturas Condicionais

Tome decisões inteligentes em seus algoritmos!

O que são Condicionais?

Condicionais são estruturas de controle que permitem que um programa tome decisões baseadas em condições específicas.



Por que são importantes?

  • Tomada de Decisão: Permitem que programas respondam de forma diferente a situações diferentes
  • Controle de Fluxo: Determinam qual código será executado
  • Lógica de Negócio: Implementam regras e validações
  • Interatividade: Criam programas que respondem às ações do usuário

Exemplo do Dia a Dia

"Se está chovendo, então levo guarda-chuva,
senão saio sem guarda-chuva"

Esta é uma decisão condicional que fazemos naturalmente!

Estrutura Condicional IF

Sintaxe Básica

if condição:
  # código a ser executado
  # se a condição for verdadeira

Exemplo Prático: Verificar idade

idade = 18
if idade >= 18:
    print(" Vocé é maior de idade")
    print(" Pode dirigir!")
        
# Resultado:
# Como idade = 18 e 18 >= 18 é True, as duas mensagens serão exibidas.

Outro Exemplo: Calcular área de um retângulo

# Entrada de dados
base = float(input("Digite o valor da base: "))
altura = float(input("Digite o valor da altura: "))

# Processamento
area = base * altura

# Saída de dados
print(f"A area do retangulo de base {base} e altura {altura} eh {area}")

Exercício 1: Par ou Ímpar


Criar um programa que verifica se um número é par ou ímpar

Conceito

Um número é par quando é divisível por 2 (resto da divisão por dois é igual a zero).

Usamos o operador % (módulo) para encontrar o resto.

Exemplos:

  • 8 % 2 = 0 (par)
  • 7 % 2 = 1 (ímpar)
  • 10 % 2 = 0 (par)
numero = int(input("Digite um número: "))

if numero % 2 == 0:
    print(f"{numero} é PAR")
else:
    print(f"{numero} é ÍMPAR")

# Explicação:
# O programa lê um número do usuário.
# Usa a condicional if para verificar se o resto da divisão do número por 2 é 0.
# Se for, imprime que o número é par; caso contrário, imprime que é ímpar.

Algumas regras importantes da linguagem Python


Operadores de Comparação

  • ==........ significa "Igual a"
  • !=........ significa "Diferente de"
  • <........ significa "Menor que"
  • >........ significa "Maior que"
  • <=........ significa "Menor ou igual"
  • >=........ significa "Maior ou igual"

Exemplos:

# Comparações numéricas
print(5 == 5)    # True
print(5 != 3)    # True
print(10 > 7)    # True
print(4 <= 4)    # True

# Comparações de strings
nome = "Ana"
print(nome == "Ana")     # True
print(nome != "João")    # True

Dica

Use == para comparar (não =). O símbolo = é usado para atribuir valores!


Operadores Lógicos


AND ("E" lógico): Ambas condições devem ser verdadeiras

idade = 20
renda = 3000

if idade >= 18 and renda >= 2000:
print("Aprovado para empréstimo")

OR ("OU" lógico): Pelo menos uma condição deve ser verdadeira

dia = "sábado"

if dia == "sábado" or dia == "domingo":
  print("É final de semana!")

NOT ("NÃO" lógico): Inverte o valor da condição

chuva = False

if not chuva:
  print("Vou sair sem guarda-chuva")

topic Aninhamento de Condicionais

O que é Aninhamento?

É colocar uma estrutura condicional dentro de outra, criando estruturas de decisões mais complexas.


usuario_valido = True
senha_correta = True
conta_ativa = True

if usuario_valido:
    print("Usuário encontrado")
    
    if senha_correta:
        print("Senha correta")
        
        if conta_ativa:
            print("Acesso liberado!")
            print("Bem-vindo ao sistema")
        else:
            print("Conta inativa. Contate o suporte")
    else:
        print("Senha incorreta")
        print("Tente novamente")
else:
    print("Usuário não encontrado")

Dica

Use aninhamento quando a segunda condição só faz sentido se a primeira for verdadeira.

Estrutura Condicional IF/ELSE

Sintaxe Básica

if condição:
    # código se TRUE
else:
    # código se FALSE

Quando usar:

  • Quando há duas opções mutuamente exclusivas
  • Para garantir que sempre uma ação seja executada
  • Situações de "ou isso ou aquilo"


Exemplo: Verificar Temperatura

temperatura = 25

if temperatura > 30:
  print("Está muito quente!")
  print("Vou ligar o ar condicionado")
else:
  print("Temperatura agradável")
  print("Não preciso de ar condicionado")
        
  
# Resultado:
# Como 25 não é > 30, executa o bloco else.

Exercício 3: Classificar Triângulos (Parte 1)


Verificar se três lados informados podem formar um triângulo.

📏 Regra Fundamental

Para três lados formarem um triângulo:

  • A soma de dois lados deve ser maior que o terceiro
  • Isso deve ser válido para todas as combinações

Exemplo:

Lados: 3, 4, 5

  • 3 + 4 = 7 > 5 ✓
  • 3 + 5 = 8 > 4 ✓
  • 4 + 5 = 9 > 3 ✓

Resultado: É um triângulo!

a = float(input("Lado A: "))
b = float(input("Lado B: "))
c = float(input("Lado C: "))

if (a + b > c) and (a + c > b) and (b + c > a):
    print("Os lados formam um triângulo!")
    # Próximo slide: classificar tipo
else:
    print("Os lados NÃO formam um triângulo")

# Explicação:
# O programa lê os três lados do usuário.
# Usa uma condicional if;else com operadores lógicos 
# para verificar a regra fundamental.
# Imprime se os lados formam ou não um triângulo.

Estrutura Condicional
IF/ELIF/ELSE

Sintaxe Básica

if primeira_condição:
    # código para primeira condição
elif segunda_condição:
    # código para segunda condição
elif terceira_condição:
    # código para terceira condição
(...)
else:
    # código se nenhuma condição for verdadeira

Quando usar:

  • Quando há duas opções mutuamente exclusivas
  • Para garantir que sempre uma ação seja executada
  • Situações de "ou isso ou aquilo"



Exemplo: Sistema de Notas

nota = 85

if nota >= 90:

Exercício 4: Classificar Triângulos (Parte 2)


Verificar se três lados informados podem formar um triângulo. Se formar um triângulo, qual o tipo?

Classificação

  • Equilátero: 3 lados iguais
  • Isósceles: 2 lados iguais
  • Escaleno: 3 lados diferentes
a = float(input("Lado A: "))
b = float(input("Lado B: "))
c = float(input("Lado C: "))

if (a + b > c) and (a + c > b) and (b + c > a):
    print("Forma um triângulo!")
    
    if a == b == c:
        print("Tipo: EQUILÁTERO")
    elif a == b or a == c or b == c:
        print("Tipo: ISÓSCELES")
    else:
        print("Tipo: ESCALENO")
else:
    print("NÃO forma um triângulo")


# Testes:
# Entrada: 3, 4, 5
# Saída: "Forma um triângulo!" e "Tipo: ESCALENO
# Entrada: 2, 2, 2
# Saída: "Forma um triângulo!" e "Tipo: EQUILÁTERO"

Sistema de Gerenciamento de Tarefas Simples (Parte 2):

Modifique o prejeto gerado na Aula 1 para permitir que o usuário marque uma tarefa como concluída ou não concluída.


Objetivos do Projeto:

  • Peça ao usuário para inserir o nome da tarefa.
  • Após adicionar a tarefa, pergunte se a tarefa está concluída (S/N).
  • Armazene essa informação e exiba o status junto com o nome da tarefa.

Exemplo de saída: Tarefa: Estudar Python - Status: Pendente


Versão Anterior do código:

# Sistema de Gerenciamento de Tarefas
print("=== SISTEMA DE TAREFAS ===")

# Solicitar nome da tarefa
nome_tarefa = input("Digite o nome da tarefa: ")

# Confirmar adição da tarefa
print(f"Tarefa '{nome_tarefa}' adicionada com sucesso!")
        
# Sistema de Gerenciamento de Tarefas - Versão Atualizada
print("=== SISTEMA DE TAREFAS ===")

# Solicitar nome da tarefa
nome_tarefa = input("Digite o nome da tarefa: ")

# Solicitar status da tarefa
status_tarefa = input("A tarefa está concluída? (S/N): ")

# Teste para verificar se a tarefa foi concluida
if status_tarefa.upper() == "S":
    status_tarefa_verificada = "Concluída"
else:
    status_tarefa = "Pendente"

# Confirmar adição da tarefa
print(f"Tarefa '{nome_tarefa}' adicionada com sucesso!")
print(f"Status: {status_tarefa_verificada}")
